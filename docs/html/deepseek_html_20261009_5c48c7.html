常见问题

你可能想知道

拍摄前需要准备什么？

你只需要确定拍摄风格和大致场景，剩下的交给我们。我们会提前发送拍摄指南，包括服装建议、道具准备和参考样片。

成片多久能交付？

基础套餐 7 个工作日，专业套餐 3 个工作日。如需加急，可沟通 48 小时出片（可能产生额外费用）。

你们在哪些城市可以拍摄？

我们总部在上海，北京、深圳、成都、杭州均有常驻团队。其他城市可安排差旅拍摄，具体费用请咨询顾问。

后期修图可以指定风格吗？

当然可以。拍摄前我们会与你确认参考图，调色师会根据你的品牌调性或个人喜好进行针对性调色。

准备好记录你的故事了吗？

无论是一次个人写真，还是品牌年度视觉，Aperture 都能为你量身打造。

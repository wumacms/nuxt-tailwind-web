## 二、状态驱动样式的统一模式（约 2 分钟）

**【录屏提示】** 屏幕显示一段用 data 属性驱动样式的代码。

在 Vue 里，我们通常用 `:class` 绑定条件样式。但这种方式在**多状态**场景下会很啰嗦。

V4 有一个更优雅的做法：**用 data 属性 + Tailwind 变体。**

**【录屏提示】** 写示例。

```html
<button
  :data-active="active || undefined"
  class="px-4 py-2 text-gray-600 data-[active]:text-brand-500 data-[active]:font-semibold"
>
  标签
</button>
```

`data-[active]` 的意思是"当元素有 `data-active` 属性时"。这样样式逻辑在 class 里，Vue 只管设置属性。

**【录屏提示】** 镜头拉近。

**这个模式的好处是：状态和样式解耦。** Vue 负责"数据是什么"，CSS 负责"数据怎么显示"。

## 三、Tabs 组件（约 4 分钟）

好，我们用这个模式做 Tabs。

**【录屏提示】** 新建 `components/ui/AppTabs.vue`。

```vue
<script setup lang="ts">
interface Tab {
  key: string
  label: string
}

interface Props {
  modelValue: string
  tabs: Tab[]
}

const props = defineProps<Props>()
const emit = defineEmits<{
  'update:modelValue': [value: string]
}>()
</script>

<template>
  <div>
    <div role="tablist" class="flex gap-1 border-b border-gray-200">
      <button
        v-for="tab in tabs"
        :key="tab.key"
        role="tab"
        :aria-selected="modelValue === tab.key"
        :data-active="modelValue === tab.key || undefined"
        class="px-4 py-2.5 text-sm font-medium text-gray-500 border-b-2 border-transparent transition-colors hover:text-gray-900 data-[active]:text-brand-500 data-[active]:border-brand-500"
        @click="emit('update:modelValue', tab.key)"
      >
        {{ tab.label }}
      </button>
    </div>

    <div role="tabpanel" class="mt-6">
      <slot />
    </div>
  </div>
</template>
```

**【录屏提示】** 边写边讲。

几个关键点。

**第一，`role="tablist"`、`role="tab"`、`role="tabpanel"`。** 无障碍必需，屏幕阅读器靠这个理解结构。

**第二，`aria-selected`。** 告诉屏幕阅读器哪个 Tab 选中。

**第三，`data-active` + `data-[active]:`。** 状态驱动样式。

**第四，`v-model` 支持。** 通过 `modelValue` + `update:modelValue`。

**第五，`border-b-2 border-transparent`。** 未选中时边框透明，选中时变品牌色。**这样切换时不会跳动。**

**【录屏提示】** 镜头拉近，语气加重。

**"透明占位"是常用的技巧。** 当元素选中/未选中样式差一个边框或加粗时，用透明占位避免布局抖动。

## 四、键盘导航（约 1 分 30 秒）

**【录屏提示】** 镜头切回讲师，语气放慢。

Tabs 有一个**无障碍要求**：支持键盘导航。

标准行为是：

- `Tab` 键聚焦到当前选中的 Tab
- `←` 和 `→` 键在 Tab 之间移动

**【录屏提示】** 简单示意代码。

```ts
function onKeydown(e: KeyboardEvent, index: number) {
  if (e.key === 'ArrowRight') {
    const next = (index + 1) % props.tabs.length
    emit('update:modelValue', props.tabs[next].key)
  } else if (e.key === 'ArrowLeft') {
    const prev = (index - 1 + props.tabs.length) % props.tabs.length
    emit('update:modelValue', props.tabs[prev].key)
  }
}
```

**【录屏提示】** 镜头切回讲师。

**企业站不一定要做这么完整**，但如果你的项目有 a11y 要求，这就是标准做法。我们第七章会深入讲。

## 五、分页组件（约 2 分钟）

好，接下来做分页。

**【录屏提示】** 新建 `components/ui/AppPagination.vue`。

```vue
<script setup lang="ts">
interface Props {
  page: number
  total: number
  perPage?: number
}

const props = withDefaults(defineProps<Props>(), {
  perPage: 10,
})

const emit = defineEmits<{
  'update:page': [value: number]
}>()

const totalPages = computed(() => Math.ceil(props.total / props.perPage))

const pages = computed(() => {
  const t = totalPages.value
  const c = props.page
  const range: (number | '...')[] = []

  if (t <= 7) {
    for (let i = 1; i <= t; i++) range.push(i)
  } else {
    range.push(1)
    if (c > 3) range.push('...')
    for (let i = Math.max(2, c - 1); i <= Math.min(t - 1, c + 1); i++) range.push(i)
    if (c < t - 2) range.push('...')
    range.push(t)
  }
  return range
})
</script>

<template>
  <nav aria-label="分页" class="flex items-center justify-center gap-1">
    <button
      :disabled="page <= 1"
      class="px-3 py-2 text-sm rounded-md text-gray-600 hover:bg-gray-100 disabled:opacity-40 disabled:cursor-not-allowed"
      @click="emit('update:page', page - 1)"
    >
      上一页
    </button>

    <template v-for="(p, i) in pages" :key="i">
      <span v-if="p === '...'" class="px-3 py-2 text-gray-400">…</span>
      <button
        v-else
        :data-active="p === page || undefined"
        class="px-3 py-2 text-sm rounded-md text-gray-600 hover:bg-gray-100 data-[active]:bg-brand-500 data-[active]:text-white"
        @click="emit('update:page', p)"
      >
        {{ p }}
      </button>
    </template>

    <button
      :disabled="page >= totalPages"
      class="px-3 py-2 text-sm rounded-md text-gray-600 hover:bg-gray-100 disabled:opacity-40 disabled:cursor-not-allowed"
      @click="emit('update:page', page + 1)"
    >
      下一页
    </button>
  </nav>
</template>
```

**【录屏提示】** 边写边讲。

几个关键点。

**第一，省略号逻辑。** 页数多时，只显示当前页附近的页码，两端各保留首尾页。

**第二，`data-active` 驱动当前页样式。** 品牌色背景 + 白字。

**第三，`disabled` 状态。** 首页禁用"上一页"，末页禁用"下一页"。

**第四，`aria-label="分页"`。** 无障碍。

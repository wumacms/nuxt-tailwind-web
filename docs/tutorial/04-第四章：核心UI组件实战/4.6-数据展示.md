# 4.6-数据展示

**【录屏提示】** 开场：讲师出镜，背景为表格、列表、统计卡。

---

## 一、开场白（约 30 秒）

好，欢迎回来。

这一节我们做**数据展示**组件——表格、列表、统计卡。

它们主要出现在**后台**或者**数据密集的页面**。这一节的难点是**响应式**——表格在手机上怎么处理，是个经典问题。

---

## 二、表格的响应式难题（约 2 分钟）

**【录屏提示】** 屏幕显示一个横向溢出的表格。

先看问题。

表格天生是"宽"的——多列并排。手机屏幕窄，放不下。常见做法是**横向滚动**，但体验很差：用户要左右滑，还得记住表头。

**【录屏提示】** 镜头切回讲师。

**更好的做法是：在手机上把表格"变成卡片"。**

每一行变成一张卡片，每个单元格变成"标签 + 值"。

**【录屏提示】** 屏幕显示桌面表格 vs 手机卡片的对比。

**这就是"响应式表格"的核心思想——不是缩小，是换形态。**

---

## 三、实现响应式表格（约 4 分钟）

**【录屏提示】** 新建 `components/ui/AppTable.vue`。

```vue
<script setup lang="ts">
interface Column {
  key: string
  label: string
  align?: 'left' | 'center' | 'right'
}

interface Props {
  columns: Column[]
  rows: Record<string, any>[]
}

defineProps<Props>()
</script>

<template>
  <div class="w-full">
    <!-- 桌面：表格 -->
    <table class="hidden md:table w-full text-sm">
      <thead>
        <tr class="border-b border-gray-200">
          <th
            v-for="col in columns"
            :key="col.key"
            :class="[
              'px-4 py-3 font-medium text-gray-600',
              col.align === 'right' ? 'text-right' :
              col.align === 'center' ? 'text-center' : 'text-left',
            ]"
          >
            {{ col.label }}
          </th>
        </tr>
      </thead>
      <tbody>
        <tr
          v-for="(row, i) in rows"
          :key="i"
          class="border-b border-gray-100 hover:bg-gray-50 transition-colors"
        >
          <td
            v-for="col in columns"
            :key="col.key"
            :class="[
              'px-4 py-3',
              col.align === 'right' ? 'text-right' :
              col.align === 'center' ? 'text-center' : 'text-left',
            ]"
          >
            <slot :name="col.key" :row="row" :value="row[col.key]">
              {{ row[col.key] }}
            </slot>
          </td>
        </tr>
      </tbody>
    </table>

    <!-- 移动：卡片 -->
    <div class="md:hidden space-y-4">
      <div
        v-for="(row, i) in rows"
        :key="i"
        class="bg-white rounded-lg border border-gray-100 p-4 space-y-2"
      >
        <div
          v-for="col in columns"
          :key="col.key"
          class="flex justify-between gap-4 text-sm"
        >
          <span class="text-gray-500 shrink-0">{{ col.label }}</span>
          <span class="text-gray-900 text-right">
            <slot :name="col.key" :row="row" :value="row[col.key]">
              {{ row[col.key] }}
            </slot>
          </span>
        </div>
      </div>
    </div>
  </div>
</template>
```

**【录屏提示】** 边写边讲。

几个关键点。

**第一，两套 DOM。** 桌面用 `<table>`，移动用卡片。用 `hidden md:table` 和 `md:hidden` 切换。

**第二，作用域插槽。** `:name="col.key"` 让调用方为特定列自定义渲染。比如给"状态"列渲染一个标签。

**第三，`align` 支持对齐。** 数字列通常右对齐。

**第四，`shrink-0`。** 移动卡片里，标签不被压缩。

**【录屏提示】** 镜头拉近，语气加重。

**"两套 DOM"是响应式表格最实用的方案。** 虽然代码多了一倍，但体验最好。**不要为了省代码用横向滚动**，那是偷懒。

## 四、列表组件（约 1 分 30 秒）

好，列表比表格简单，通常不需要这么复杂。

**【录屏提示】** 写一个列表。

```vue
<ul class="divide-y divide-gray-100">
  <li
    v-for="item in items"
    :key="item.id"
    class="py-4 flex items-center gap-4 hover:bg-gray-50 transition-colors"
  >
    <div class="flex-1 min-w-0">
      <p class="font-medium truncate">{{ item.title }}</p>
      <p class="text-sm text-gray-500 truncate">{{ item.description }}</p>
    </div>
    <span class="text-xs text-gray-400 shrink-0">{{ item.date }}</span>
  </li>
</ul>
```

**【录屏提示】** 镜头切回讲师。

**`divide-y` 是列表神器。** 它自动在子元素之间加边框，比手动写 `border-b` 干净。

**`min-w-0` + `truncate` 让长文本省略。** 这个组合在 flex 布局里很常用。

## 五、统计卡（约 1 分 30 秒）

最后做**统计卡**——大数字 + 描述 + 图标。

**【录屏提示】** 新建 `components/ui/StatCard.vue`。

```vue
<script setup lang="ts">
interface Props {
  label: string
  value: string | number
  trend?: number
  icon?: string
}

defineProps<Props>()
</script>

<template>
  <div class="bg-white rounded-lg border border-gray-100 p-6">
    <div class="flex items-center justify-between">
      <span class="text-sm text-gray-500">{{ label }}</span>
      <span v-if="icon" class="text-brand-500"><Icon :name="icon" /></span>
    </div>
    <p class="mt-3 text-3xl font-display font-bold text-gray-900">
      {{ value }}
    </p>
    <p
      v-if="trend !== undefined"
      :class="[
        'mt-2 text-sm',
        trend >= 0 ? 'text-green-600' : 'text-red-600',
      ]"
    >
      {{ trend >= 0 ? '↑' : '↓' }} {{ Math.abs(trend) }}%
    </p>
  </div>
</template>
```

**【录屏提示】** 边写边讲。

**第一，`text-3xl font-display font-bold` 让数字醒目。** 统计卡的重点就是数字。

**第二，`trend` 正负用不同颜色。** 涨绿跌红。

**第三，`Math.abs` 保证箭头方向由符号决定，数值不带负号。**

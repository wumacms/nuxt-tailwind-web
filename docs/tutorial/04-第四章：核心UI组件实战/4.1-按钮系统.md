# 4.1-按钮系统

**【录屏提示】** 开场：讲师出镜，背景为成品站的按钮矩阵（所有变体组合）。

---

## 一、开场白（约 30 秒）

好，欢迎来到第四章。

第三章我们把布局骨架搭完了。从这一章开始，我们做**零件**——核心 UI 组件。

第一个组件，也是最基础、最常被复用的组件：**按钮**。

你别小看按钮。一个企业站里，按钮可能出现几十次。如果每个都随手写，改一次品牌色就得改几十处。这一节，我们做一套**类型安全、可扩展、可维护**的按钮系统。

---

## 二、按钮需要支持什么（约 1 分 30 秒）

先想清楚需求。

**【录屏提示】** 屏幕显示按钮的所有变体。

我们企业站的按钮，需要支持：

**第一，变体（variant）。** 主按钮、次按钮、危险按钮、幽灵按钮。不同场景用不同变体。

**第二，尺寸（size）。** 小、中、大。不同位置用不同尺寸。

**第三，状态。** 正常、禁用、加载中。

**第四，形态。** 可以是 `<button>`，也可以是链接（`<NuxtLink>` 或 `<a>`）。

**第五，图标位。** 左边有图标、右边有图标、只有图标。

**【录屏提示】** 镜头切回讲师。

**这五个维度，就是我们的 API 设计。** 接下来逐个实现。

---

## 三、类型定义（约 2 分钟）

好，我们先定义类型。

**【录屏提示】** 新建 `components/ui/AppButton.vue`，先写 script。

```ts
type Variant = 'primary' | 'secondary' | 'danger' | 'ghost'
type Size = 'sm' | 'md' | 'lg'

interface Props {
  variant?: Variant
  size?: Size
  disabled?: boolean
  loading?: boolean
  block?: boolean
  to?: string
  href?: string
}
```

**【录屏提示】** 边写边讲。

**第一，`Variant` 和 `Size` 用联合类型。** 限定取值，TS 编译期就能发现拼写错误。

**第二，`disabled` 和 `loading` 是布尔。** 控制状态。

**第三，`block` 控制是否撑满宽度。** 有些场景需要全宽按钮。

**第四，`to` 和 `href`。** 有 `to` 时渲染成 `NuxtLink`，有 `href` 时渲染成 `a`，都没有时渲染成 `button`。这就是**多态组件**。

---

## 四、类名映射表（约 2 分 30 秒）

好，接下来是核心——**把变体映射到类名**。

**【录屏提示】** 写映射表。

```ts
const baseClasses =
  'inline-flex items-center justify-center gap-2 font-medium rounded-md transition-colors ' +
  'focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-brand-500 focus-visible:ring-offset-2 ' +
  'disabled:opacity-50 disabled:cursor-not-allowed'

const variantClasses: Record<Variant, string> = {
  primary: 'bg-brand-500 text-white hover:bg-brand-600',
  secondary: 'bg-gray-100 text-gray-900 hover:bg-gray-200',
  danger: 'bg-red-500 text-white hover:bg-red-600',
  ghost: 'bg-transparent text-brand-500 hover:bg-brand-50',
}

const sizeClasses: Record<Size, string> = {
  sm: 'px-3 py-1.5 text-sm',
  md: 'px-4 py-2 text-base',
  lg: 'px-6 py-3 text-lg',
}
```

**【录屏提示】** 镜头拉近，逐段解释。

这里我要重点讲几个点。

**第一，`baseClasses` 是所有按钮共有的。** 布局（`inline-flex`）、对齐、字体、圆角、过渡、焦点、禁用态，都在这里。

**第二，`focus-visible:ring-*` 是焦点样式。** 用 `focus-visible` 而不是 `focus`，意思是**只有键盘导航时才显示焦点环**，鼠标点击不显示。这是现代无障碍的最佳实践。

**第三，`disabled:` 变体。** Tailwind 内置了 `disabled:`，直接写就行。

**第四，所有类名都是完整字符串。** 这是我们 2.3、2.5 反复强调的——**保证 Tailwind 能扫到，TS 能约束。**

**【录屏提示】** 镜头切回讲师。

**注意，映射表的 value 里不要写 `hover:`、`focus:` 之外的状态类**，那些放 base 或单独处理。保持映射表干净。

## 五、多态渲染（约 2 分钟）

好，接下来实现"根据 props 决定渲染成什么标签"。

**【录屏提示】** 写模板。

```vue
<script setup lang="ts">
import { computed } from 'vue'

const props = withDefaults(defineProps<Props>(), {
  variant: 'primary',
  size: 'md',
  disabled: false,
  loading: false,
  block: false,
})

const tag = computed(() => {
  if (props.to) return resolveComponent('NuxtLink')
  if (props.href) return 'a'
  return 'button'
})

const classes = computed(() => [
  baseClasses,
  variantClasses[props.variant],
  sizeClasses[props.size],
  props.block && 'w-full',
])

const attrs = computed(() => {
  if (props.to) return { to: props.to }
  if (props.href) return { href: props.href, target: '_blank', rel: 'noopener' }
  return { type: 'button', disabled: props.disabled || props.loading }
})
</script>

<template>
  <component :is="tag" :class="classes" v-bind="attrs">
    <span v-if="loading" class="animate-spin">⟳</span>
    <slot />
  </component>
</template>
```

**【录屏提示】** 边写边讲。

几个关键点。

**第一，`resolveComponent('NuxtLink')`。** 因为 NuxtLink 是自动导入的，在 `<component :is>` 里用要显式解析。

**第二，`attrs` 是计算属性。** 根据渲染成什么标签，传不同的属性。

**第三，`disabled` 只在 button 上生效。** 链接没有 disabled 属性，所以要么用 CSS 模拟，要么用 `aria-disabled`。这里简单处理，实际项目可以进一步完善。

**第四，`loading` 时显示 spinner。** 这里用了简单的字符，实际可以用图标组件。

**【录屏提示】** 镜头拉近，语气加重。

**多态组件是 UI 库的常见模式。** 它让一个组件既能当按钮，又能当链接，**调用方不用关心底层标签**。这是好的 API 设计。

## 六、使用与验证（约 1 分钟）

**【录屏提示】** 在页面里写示例。

```vue
<AppButton>默认按钮</AppButton>
<AppButton variant="secondary" size="lg">次按钮</AppButton>
<AppButton variant="danger" :loading="true">删除</AppButton>
<AppButton to="/contact" variant="primary">联系我们</AppButton>
<AppButton block>全宽按钮</AppButton>
```

**【录屏提示】** 切浏览器，展示所有变体。

你看，所有组合都正常渲染。注意最后一个"联系我们"，它实际上是一个 `<NuxtLink>`，但外观和按钮一样。

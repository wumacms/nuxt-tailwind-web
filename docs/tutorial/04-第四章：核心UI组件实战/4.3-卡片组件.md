# 4.3-卡片组件

**【录屏提示】** 开场：讲师出镜，背景为各种卡片形态。

---

## 一、开场白（约 30 秒）

好，欢迎回来。

这一节我们做**卡片组件**。

卡片是企业站**出现频率最高**的元素。产品卡、新闻卡、团队卡、案例卡……几乎每个页面都有。

它们看起来不同，但**结构高度相似**：一张图、一个标题、一段描述、一个操作。这一节，我们做一个**可配置、可扩展**的卡片系统。

---

## 二、卡片的通用结构（约 2 分钟）

先拆解。

**【录屏提示】** 屏幕显示卡片的结构分解。

一张卡片，通常有这几块：

**第一，媒体区。** 图片、视频、图标。**可选。**

**第二，内容区。** 标题、描述、标签、元信息。

**第三，操作区。** 按钮、链接。**可选。**

**【录屏提示】** 镜头切回讲师。

有的卡片有图，有的没有；有的有按钮，有的没有。所以我们的卡片要**支持插槽**，让调用方决定放什么。

**核心思想：卡片负责"外壳 + 布局"，内容通过插槽传入。**

## 三、基础卡片（约 2 分 30 秒）

**【录屏提示】** 新建 `components/ui/AppCard.vue`。

```vue
<script setup lang="ts">
interface Props {
  padding?: 'none' | 'sm' | 'md' | 'lg'
  hoverable?: boolean
}

const props = withDefaults(defineProps<Props>(), {
  padding: 'md',
  hoverable: false,
})

const paddingClasses = {
  none: '',
  sm: 'p-4',
  md: 'p-6',
  lg: 'p-8',
} as const
</script>

<template>
  <div
    :class="[
      'bg-white rounded-lg shadow-card border border-gray-100 overflow-hidden',
      paddingClasses[padding],
      hoverable && 'transition-all duration-300 hover:shadow-lg hover:-translate-y-1',
    ]"
  >
    <slot />
  </div>
</template>
```

**【录屏提示】** 边写边讲。

几个关键点。

**第一，`shadow-card` 是我们自定义的令牌。** 比默认阴影更柔和。

**第二，`overflow-hidden`。** 让图片的圆角跟随卡片。**这是卡片有图时的必备。**

**第三，`hoverable` 的悬停效果。** `hover:shadow-lg hover:-translate-y-1`，让卡片"浮起来"。

**第四，`padding` 用 `as const` 映射表。** 保证 Tailwind 能扫到。

**【录屏提示】** 镜头拉近。

**注意，`hover:-translate-y-1` 是位移效果。** 需要配合 `transition-all` 才能平滑过渡。这两个一般要成对出现。

## 四、带图的卡片（约 2 分 30 秒）

好，接下来做**带图的卡片**。这是最常见的形态。

**【录屏提示】** 新建 `components/ui/AppMediaCard.vue`。

```vue
<script setup lang="ts">
interface Props {
  to?: string
  image?: string
  imageAlt?: string
  title?: string
  description?: string
  tag?: string
}

defineProps<Props>()
</script>

<template>
  <component
    :is="to ? resolveComponent('NuxtLink') : 'div'"
    :to="to"
    class="group block bg-white rounded-lg shadow-card border border-gray-100 overflow-hidden transition-all duration-300 hover:shadow-lg"
  >
    <div v-if="image" class="aspect-[16/10] overflow-hidden bg-gray-100">
      <NuxtImg
        :src="image"
        :alt="imageAlt || title"
        class="w-full h-full object-cover transition-transform duration-500 group-hover:scale-105"
        loading="lazy"
      />
    </div>

    <div class="p-6">
      <span v-if="tag" class="inline-block text-xs font-medium text-brand-500 bg-brand-50 rounded px-2 py-1 mb-3">
        {{ tag }}
      </span>
      <h3 v-if="title" class="text-lg font-semibold text-gray-900 group-hover:text-brand-500 transition-colors">
        {{ title }}
      </h3>
      <p v-if="description" class="mt-2 text-sm text-gray-600 line-clamp-2">
        {{ description }}
      </p>
      <slot />
    </div>
  </component>
</template>
```

**【录屏提示】** 边写边讲。

几个关键点。

**第一，`group` 和 `group-hover:`。** 鼠标悬停卡片时，图片放大、标题变色。**这是 Tailwind 最实用的变体之一。**

**第二，`aspect-[16/10]`。** 固定图片比例，避免不同尺寸图片导致卡片高度不一。**这是卡片列表整齐的关键。**

**第三，`object-cover`。** 图片裁切填满容器，不会变形。

**第四，`line-clamp-2`。** 描述文字最多两行，超出省略。**这解决了"描述长短不一"的问题。**

**第五，`NuxtImg` 加 `loading="lazy"`。** 图片懒加载，性能优化。

**【录屏提示】** 镜头拉近，语气加重。

**`group-hover` + `line-clamp` + `aspect-*`，这三个是卡片组件的"三件套"。** 你在做任何卡片时，都应该想到它们。

## 五、卡片列表的栅格（约 1 分 30 秒）

好，卡片很少单独出现，通常是**列表**。

**【录屏提示】** 写一个卡片列表。

```vue
<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">
  <AppMediaCard
    v-for="item in items"
    :key="item.id"
    :to="`/news/${item.slug}`"
    :image="item.cover"
    :title="item.title"
    :description="item.excerpt"
    tag="新闻"
  />
</div>
```

**【录屏提示】** 切浏览器，展示响应式变化。

手机一列、平板两列、桌面三列。**这就是移动优先的断点组合。**

**【录屏提示】** 镜头切回讲师。

**注意 `gap-6`。** 卡片的间距要统一，和我们的布局系统对齐。

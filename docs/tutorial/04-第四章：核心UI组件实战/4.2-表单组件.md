## 一、开场白（约 30 秒）

这一节我们做**表单组件**。

表单在企业站里，通常出现在"联系我们""预约咨询""订阅"这些页面。它的特点是：**状态多**——正常、聚焦、错误、禁用、必填……每个状态都要有对应的视觉反馈。

这一节，我们做一套风格统一、状态完整的表单控件。

## 二、表单控件的共性（约 2 分钟）

先看共性。

**【录屏提示】** 屏幕显示 Input、Textarea、Select 的对比。

不管是输入框、文本域还是下拉框，它们都有**共同的结构**：

**第一，label。** 输入框的标签，说明这个字段是什么。

**第二，控件本身。** input / textarea / select。

**第三，辅助文本。** 提示文字或错误信息。

**第四，状态。** 正常、聚焦、错误、禁用、必填。

**【录屏提示】** 镜头切回讲师。

**既然共性这么多，我们就抽一个"表单字段"的包装组件。**

它负责 label、错误提示、间距；内部的控件通过插槽传入。

## 三、FormField 包装组件（约 2 分 30 秒）

**【录屏提示】** 新建 `components/ui/FormField.vue`。

```vue
<script setup lang="ts">
interface Props {
  label?: string
  error?: string
  hint?: string
  required?: boolean
  for?: string
}

defineProps<Props>()
</script>

<template>
  <div class="space-y-1.5">
    <label
      v-if="label"
      :for="for"
      class="block text-sm font-medium text-gray-700"
    >
      {{ label }}
      <span v-if="required" class="text-red-500" aria-hidden="true">*</span>
    </label>

    <slot />

    <p v-if="error" class="text-sm text-red-500">{{ error }}</p>
    <p v-else-if="hint" class="text-sm text-gray-500">{{ hint }}</p>
  </div>
</template>
```

**【录屏提示】** 边写边讲。

几个关键点。

**第一，`space-y-1.5` 控制 label、控件、提示之间的间距。** 统一节奏。

**第二，`for` 属性关联 label 和控件。** 无障碍必需。

**第三，`required` 用星号标记。** 用 `aria-hidden` 让屏幕阅读器忽略星号，因为 `required` 属性本身会告诉屏幕阅读器。

**第四，错误优先于提示。** `v-if="error"` 在前，有错误就不显示提示。

## 四、Input 组件（约 2 分 30 秒）

好，接下来做输入框。

**【录屏提示】** 新建 `components/ui/AppInput.vue`。

```vue
<script setup lang="ts">
interface Props {
  modelValue?: string | number
  type?: string
  placeholder?: string
  disabled?: boolean
  error?: boolean
  id?: string
}

const props = withDefaults(defineProps<Props>(), {
  type: 'text',
  disabled: false,
  error: false,
})

const emit = defineEmits<{
  'update:modelValue': [value: string]
}>()

const baseClasses =
  'block w-full rounded-md border bg-white px-3 py-2 text-sm ' +
  'placeholder:text-gray-400 ' +
  'transition-colors ' +
  'focus:outline-none focus:ring-2 focus:ring-offset-0 ' +
  'disabled:bg-gray-50 disabled:text-gray-500 disabled:cursor-not-allowed'

const stateClasses = computed(() =>
  props.error
    ? 'border-red-500 focus:border-red-500 focus:ring-red-500/20'
    : 'border-gray-300 focus:border-brand-500 focus:ring-brand-500/20'
)
</script>

<template>
  <input
    :id="id"
    :type="type"
    :value="modelValue"
    :placeholder="placeholder"
    :disabled="disabled"
    :aria-invalid="error || undefined"
    :class="[baseClasses, stateClasses]"
    @input="emit('update:modelValue', ($event.target as HTMLInputElement).value)"
  />
</template>
```

**【录屏提示】** 边写边讲。

几个关键点。

**第一，`v-model` 支持。** 用 `modelValue` + `update:modelValue`，这是 Vue 3 的 v-model 约定。

**第二，状态类分开。** base 和 state 分开，state 根据 `error` 动态切换。

**第三，`focus:ring-2` 加 `ring-brand-500/20`。** 聚焦时有一个柔和的品牌色光环，视觉上很舒服。

**第四，`aria-invalid`。** 错误状态告诉屏幕阅读器。

**第五，`($event.target as HTMLInputElement).value`。** TS 里事件目标类型需要断言。

**【录屏提示】** 镜头拉近，语气加重。

**`disabled:` 和 `focus:` 这些变体，配合状态类的思路，是表单控件的核心。** 把"状态 → 类名"的关系理清楚，表单就不难了。

## 五、V4 的 `has-*` 和 `peer-*` 变体（约 1 分 30 秒）

**【录屏提示】** 屏幕显示一个用 `has-*` 的例子。

V4 提供了一些**新变体**，能让表单更优雅。

**`has-*` 变体**：父元素根据子元素的状态变化。

```html
<div class="has-[:focus]:ring-2 has-[:invalid]:border-red-500">
  <input />
</div>
```

这样你不需要写 JS，父元素就能响应子元素状态。

**`peer-*` 变体**：兄弟元素之间联动。

```html
<input class="peer" />
<p class="hidden peer-invalid:block text-red-500">请输入有效内容</p>
```

输入框无效时，下面的提示自动显示。

**【录屏提示】** 镜头切回讲师。

**这两个变体，让"表单状态"可以纯 CSS 实现。** 我们后面做表单校验时，会用到。

## 六、完整表单示例（约 1 分钟）

**【录屏提示】** 在页面里组合。

```vue
<form class="space-y-5">
  <FormField label="姓名" required for="name">
    <AppInput id="name" v-model="form.name" placeholder="请输入姓名" />
  </FormField>

  <FormField label="邮箱" required for="email" :error="errors.email">
    <AppInput id="email" v-model="form.email" type="email" :error="!!errors.email" />
  </FormField>

  <FormField label="留言" for="message" hint="不超过 500 字">
    <AppTextarea id="message" v-model="form.message" rows="5" />
  </FormField>

  <AppButton type="submit">提交</AppButton>
</form>
```

**【录屏提示】** 切浏览器，展示效果。

你看，表单结构清晰，label、错误、提示都有。**而且所有控件都用了同一套样式，风格统一。**

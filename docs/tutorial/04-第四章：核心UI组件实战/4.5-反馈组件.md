## 一、开场白（约 30 秒）

好，欢迎回来。

这一节我们做**反馈组件**——Toast、Modal、Drawer。

它们的作用是**给用户即时反馈**，比如提交成功、确认操作、展示详情。

这类组件的技术难点不在样式，而在**交互**：焦点管理、滚动锁定、过渡动画、SSR 兼容。这一节，我们把这些都讲清楚。

## 二、Teleport 与 SSR（约 2 分钟）

**【录屏提示】** 屏幕显示 Teleport 示意图。

反馈组件通常要**脱离当前 DOM 层级**，直接挂在 `body` 上。因为如果挂在组件内部，可能被父元素的 `overflow: hidden` 裁掉，或者被 `z-index` 层级压住。

Vue 的 `<Teleport>` 就是干这个的。

**【录屏提示】** 写示例。

```vue
<Teleport to="body">
  <div class="fixed inset-0 z-50">...</div>
</Teleport>
```

**【录屏提示】** 镜头拉近，语气加重。

**但 SSR 环境下，`<Teleport>` 有个坑。**

服务端渲染时，`body` 不存在（服务端没有 DOM）。如果 Teleport 的目标在服务端找不到，会报错或者水合不一致。

**解决方案**：用 `<ClientOnly>` 包裹。

```vue
<ClientOnly>
  <Teleport to="body">
    ...
  </Teleport>
</ClientOnly>
```

**这样 Teleport 只在客户端执行**，避开 SSR 问题。

## 三、Modal 组件（约 3 分 30 秒）

好，我们做 Modal。

**【录屏提示】** 新建 `components/ui/AppModal.vue`。

```vue
<script setup lang="ts">
interface Props {
  modelValue: boolean
  title?: string
  size?: 'sm' | 'md' | 'lg'
}

const props = withDefaults(defineProps<Props>(), {
  size: 'md',
})

const emit = defineEmits<{
  'update:modelValue': [value: boolean]
}>()

const sizeClasses = {
  sm: 'max-w-md',
  md: 'max-w-lg',
  lg: 'max-w-2xl',
} as const

function close() {
  emit('update:modelValue', false)
}

function onKeydown(e: KeyboardEvent) {
  if (e.key === 'Escape') close()
}

watch(() => props.modelValue, (open) => {
  if (import.meta.client) {
    document.body.style.overflow = open ? 'hidden' : ''
  }
})

onMounted(() => window.addEventListener('keydown', onKeydown))
onUnmounted(() => {
  window.removeEventListener('keydown', onKeydown)
  document.body.style.overflow = ''
})
</script>

<template>
  <ClientOnly>
    <Teleport to="body">
      <Transition name="modal">
        <div
          v-if="modelValue"
          class="fixed inset-0 z-50 flex items-center justify-center p-4"
          role="dialog"
          aria-modal="true"
        >
          <div class="absolute inset-0 bg-black/50" @click="close" />

          <div
            :class="[
              'relative w-full bg-white rounded-lg shadow-xl',
              sizeClasses[size],
            ]"
          >
            <header v-if="title" class="px-6 py-4 border-b border-gray-100">
              <h3 class="text-lg font-semibold">{{ title }}</h3>
            </header>

            <div class="px-6 py-5">
              <slot />
            </div>

            <footer v-if="$slots.footer" class="px-6 py-4 border-t border-gray-100 flex justify-end gap-3">
              <slot name="footer" />
            </footer>
          </div>
        </div>
      </Transition>
    </Teleport>
  </ClientOnly>
</template>
```

**【录屏提示】** 边写边讲。

几个关键点。

**第一，`ClientOnly` + `Teleport`。** 避开 SSR 问题。

**第二，`role="dialog"` 和 `aria-modal="true"`。** 无障碍必需。

**第三，`Escape` 键关闭。** 监听全局 keydown。

**第四，滚动锁定。** 打开时 `body.overflow = 'hidden'`。

**第五，`Transition` 过渡。** 后面配 CSS。

**第六，`$slots.footer`。** 只在有 footer 插槽时渲染底部栏。

## 四、过渡动画（约 1 分 30 秒）

**【录屏提示】** 在 `main.css` 或组件里写过渡。

```css
.modal-enter-active,
.modal-leave-active {
  transition: opacity 0.2s ease;
}

.modal-enter-from,
.modal-leave-to {
  opacity: 0;
}

.modal-enter-active > div:last-child,
.modal-leave-active > div:last-child {
  transition: transform 0.2s ease;
}

.modal-enter-from > div:last-child,
.modal-leave-to > div:last-child {
  transform: scale(0.95);
}
```

**【录屏提示】** 镜头切回讲师。

**遮罩淡入 + 内容缩放。** 这是 Modal 的标准过渡，视觉上很舒服。

## 五、Drawer 组件（约 1 分 30 秒）

好，Drawer 和 Modal 很像，区别是**从侧边滑入**。

**【录屏提示】** 简单展示 Drawer 模板。

```vue
<Transition name="drawer">
  <div v-if="modelValue" class="fixed inset-0 z-50">
    <div class="absolute inset-0 bg-black/50" @click="close" />
    <div class="absolute right-0 top-0 bottom-0 w-80 bg-white shadow-xl">
      <slot />
    </div>
  </div>
</Transition>
```

**【录屏提示】** 镜头拉近。

**核心差异是定位和过渡方向。** 其他（焦点、滚动、Escape）都和 Modal 一样。

**所以你可以抽一个 `useOverlay` composable**，把滚动锁定、Escape 关闭、焦点管理这些逻辑复用。

## 六、Toast 系统（约 1 分 30 秒）

最后讲 Toast。

**【录屏提示】** 新建 `composables/useToast.ts`。

```ts
interface Toast {
  id: number
  message: string
  type: 'success' | 'error' | 'info'
}

const toasts = ref<Toast[]>([])
let uid = 0

export function useToast() {
  function show(message: string, type: Toast['type'] = 'info', duration = 3000) {
    const id = ++uid
    toasts.value.push({ id, message, type })
    setTimeout(() => {
      toasts.value = toasts.value.filter(t => t.id !== id)
    }, duration)
  }

  return {
    toasts,
    success: (msg: string) => show(msg, 'success'),
    error: (msg: string) => show(msg, 'error'),
    info: (msg: string) => show(msg, 'info'),
  }
}
```

**【录屏提示】** 边写边讲。

**第一，用模块级的 `ref`。** 这样多个组件共享同一份状态，不用 Pinia。

**第二，自动移除。** `setTimeout` 到期后过滤掉。

**第三，返回便捷方法。** `success`、`error`、`info`。

**【录屏提示】** 镜头切回讲师。

然后在 `app.vue` 里渲染 Toast 容器：

```vue
<ToastContainer />
```

这样就完成了全局 Toast 系统。

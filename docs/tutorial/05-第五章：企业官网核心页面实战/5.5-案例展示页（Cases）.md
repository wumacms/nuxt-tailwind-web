## 二、瀑布流的实现方式（约 2 分钟）

**【录屏提示】** 屏幕显示两种瀑布流对比。

瀑布流（Masonry）有两种实现方式。

**方式一，CSS `columns`。** 用多列布局，浏览器自动分配。

```html
<div class="columns-1 md:columns-2 lg:columns-3 gap-6">
  <div class="break-inside-avoid mb-6">...</div>
</div>
```

**优点**：零 JS，性能好。
**缺点**：顺序是**竖向填充**，不是横向。也就是说，第一列填满才填第二列。

**方式二，JS 计算。** 用库（比如 `masonry-layout`）或自己算。

**优点**：顺序可控。
**缺点**：要 JS，性能开销大，SSR 不友好。

**【录屏提示】** 镜头切回讲师。

**我的建议：企业站用 CSS `columns`。** 因为：

- 零 JS，SSR 友好
- 性能好
- 对案例展示来说，顺序不重要

**只有当你需要严格顺序时，才用 JS。** 大部分情况不需要。

## 三、实现案例墙（约 3 分钟）

**【录屏提示】** 新建 `pages/cases/index.vue`。

```vue
<script setup lang="ts">
import type { Case } from '~/types/case'

useSeoMeta({
  title: '客户案例 - 某某科技',
})

const { data: cases } = await useFetch<Case[]>('/api/cases')

const lightboxOpen = ref(false)
const currentIndex = ref(0)

function openLightbox(index: number) {
  currentIndex.value = index
  lightboxOpen.value = true
}
</script>

<template>
  <div>
    <PageHero title="客户案例" subtitle="看看我们如何帮助客户成功" />

    <PageSection>
      <div class="columns-1 md:columns-2 lg:columns-3 gap-6">
        <button
          v-for="(item, index) in cases"
          :key="item.id"
          class="block w-full mb-6 break-inside-avoid group relative rounded-lg overflow-hidden bg-gray-100 text-left"
          @click="openLightbox(index)"
        >
          <NuxtImg
            :src="item.cover"
            :alt="item.title"
            class="w-full transition-transform duration-500 group-hover:scale-105"
            loading="lazy"
          />
          <div class="absolute inset-0 bg-gradient-to-t from-black/70 via-black/0 to-black/0 opacity-0 group-hover:opacity-100 transition-opacity flex items-end p-6">
            <div>
              <h3 class="text-white font-semibold">{{ item.title }}</h3>
              <p class="text-white/80 text-sm mt-1">{{ item.client }}</p>
            </div>
          </div>
        </button>
      </div>
    </PageSection>

    <CaseLightbox
      v-model="lightboxOpen"
      :items="cases || []"
      :index="currentIndex"
      @update:index="currentIndex = $event"
    />
  </div>
</template>
```

**【录屏提示】** 边写边讲。

几个关键点。

**第一，`columns-*` 实现瀑布流。** 手机一列、平板两列、桌面三列。

**第二，`break-inside-avoid`。** 防止单个卡片被拆到两列。**这是 columns 布局的必备。**

**第三，`mb-6` 代替 gap。** `columns` 布局里 `gap` 只控制列间距，行间距要靠 `margin-bottom`。

**第四，悬停遮罩。** `bg-gradient-to-t from-black/70`，从底部黑色渐变到透明，文字浮在图片上。

**第五，`group-hover:scale-105`。** 图片悬停放大。

**第六，点击打开灯箱，传递 index。**

**【录屏提示】** 镜头拉近，语气加重。

**`columns` 布局有个坑：`gap` 只管列间距。** 行间距必须用 `mb-*`。很多人第一次用会困惑。

## 四、灯箱组件（约 3 分钟）

**【录屏提示】** 新建 `components/ui/CaseLightbox.vue`。

```vue
<script setup lang="ts">
interface Props {
  modelValue: boolean
  items: any[]
  index: number
}

const props = defineProps<Props>()
const emit = defineEmits<{
  'update:modelValue': [value: boolean]
  'update:index': [value: number]
}>()

const current = computed(() => props.items[props.index])

function close() {
  emit('update:modelValue', false)
}

function prev() {
  emit('update:index', (props.index - 1 + props.items.length) % props.items.length)
}

function next() {
  emit('update:index', (props.index + 1) % props.items.length)
}

function onKeydown(e: KeyboardEvent) {
  if (e.key === 'Escape') close()
  if (e.key === 'ArrowLeft') prev()
  if (e.key === 'ArrowRight') next()
}

watch(() => props.modelValue, (open) => {
  if (import.meta.client) {
    document.body.style.overflow = open ? 'hidden' : ''
  }
})

onMounted(() => window.addEventListener('keydown', onKeydown))
onUnmounted(() => {
  window.removeEventListener('keydown', onKeydown)
  document.body.style.overflow = ''
})
</script>

<template>
  <ClientOnly>
    <Teleport to="body">
      <Transition name="fade">
        <div
          v-if="modelValue && current"
          class="fixed inset-0 z-50 bg-black/95 flex items-center justify-center"
          role="dialog"
          aria-modal="true"
          @click.self="close"
        >
          <!-- 关闭按钮 -->
          <button
            class="absolute top-6 right-6 text-white/80 hover:text-white text-3xl"
            aria-label="关闭"
            @click="close"
          >
            ×
          </button>

          <!-- 上一张 -->
          <button
            class="absolute left-6 text-white/80 hover:text-white text-4xl"
            aria-label="上一张"
            @click="prev"
          >
            ‹
          </button>

          <!-- 内容 -->
          <div class="max-w-5xl max-h-[85vh] px-16">
            <NuxtImg
              :src="current.cover"
              :alt="current.title"
              class="max-h-[75vh] w-auto mx-auto object-contain"
            />
            <div class="mt-4 text-center text-white">
              <h3 class="text-lg font-semibold">{{ current.title }}</h3>
              <p class="text-sm text-white/60 mt-1">{{ current.client }}</p>
            </div>
          </div>

          <!-- 下一张 -->
          <button
            class="absolute right-6 text-white/80 hover:text-white text-4xl"
            aria-label="下一张"
            @click="next"
          >
            ›
          </button>
        </div>
      </Transition>
    </Teleport>
  </ClientOnly>
</template>
```

**【录屏提示】** 边写边讲。

几个关键点。

**第一，复用 `ClientOnly` + `Teleport`。** 和 Modal 一样，避开 SSR 问题。

**第二，键盘导航。** `Escape` 关闭，`←` `→` 切换。

**第三，`@click.self="close"`。** 只有点击遮罩本身才关闭，点击内容不关。**这是灯箱的标准行为。**

**第四，`object-contain`。** 图片完整显示，不裁切。灯箱里要看到完整图。

**第五，滚动锁定。** 打开时锁 body。

**第六，循环切换。** `(index + 1) % length` 实现循环。

**【录屏提示】** 镜头切回讲师。

**灯箱的交互模式，和 Modal 高度相似。** 你可以考虑抽一个 `useOverlay` composable，把"滚动锁定 + Escape 关闭 + 焦点管理"复用起来。

## 五、过渡动画（约 1 分钟）

**【录屏提示】** 写 fade 过渡。

```css
.fade-enter-active,
.fade-leave-active {
  transition: opacity 0.3s ease;
}

.fade-enter-from,
.fade-leave-to {
  opacity: 0;
}
```

**【录屏提示】** 镜头切回讲师。

**灯箱用淡入淡出就好。** 不要用缩放，因为图片本身在大幅度变化，加缩放会晕。

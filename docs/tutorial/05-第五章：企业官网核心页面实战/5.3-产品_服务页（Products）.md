## 一、开场白（约 30 秒）

好，欢迎回来。

这一节我们做**产品页**——列表和详情。

这是企业站**最核心的业务页面**。它要解决两个问题：**列表页怎么让用户快速找到想要的产品？详情页怎么让用户了解足够的信息并产生兴趣？**

而且这一节，我们第一次用到**动态路由**和**服务端数据获取**。

---

## 二、文件路由与动态路由（约 2 分钟）

**【录屏提示】** 屏幕显示文件路由映射。

先讲 Nuxt 的文件路由。

我们建这几个文件：

```text
pages/
└── products/
    ├── index.vue        → /products
    └── [slug].vue       → /products/:slug
```

`[slug].vue` 是**动态路由**。方括号里的名字，就是路由参数的名字。

**【录屏提示】** 镜头切回讲师。

**这个约定非常重要。** 有了它，我们不需要手动配置路由，文件放对位置就自动生效。

**企业站的产品详情页，就是用这种方式实现的。** 每个产品一个 URL，SEO 友好。

## 三、产品列表页（约 3 分钟）

**【录屏提示】** 新建 `pages/products/index.vue`。

```vue
<script setup lang="ts">
import type { Product } from '~/types/product'

useSeoMeta({
  title: '产品中心 - 某某科技',
  description: '我们提供全系列的企业数字化解决方案...',
})

const route = useRoute()
const activeCategory = computed(() => route.query.category as string || 'all')

const { data: products } = await useFetch<Product[]>('/api/products', {
  query: { category: activeCategory },
})

const categories = [
  { key: 'all', label: '全部' },
  { key: 'software', label: '软件产品' },
  { key: 'hardware', label: '硬件产品' },
  { key: 'service', label: '服务方案' },
]
</script>

<template>
  <div>
    <!-- 页面标题 -->
    <PageHero
      title="产品中心"
      subtitle="为企业提供全场景的数字化解决方案"
    />

    <PageSection>
      <!-- 分类筛选 -->
      <div class="flex flex-wrap justify-center gap-3 mb-12">
        <NuxtLink
          v-for="cat in categories"
          :key="cat.key"
          :to="cat.key === 'all' ? '/products' : `/products?category=${cat.key}`"
          :data-active="activeCategory === cat.key || undefined"
          class="px-5 py-2 text-sm font-medium rounded-full bg-gray-100 text-gray-600 hover:bg-gray-200 transition-colors data-[active]:bg-brand-500 data-[active]:text-white"
        >
          {{ cat.label }}
        </NuxtLink>
      </div>

      <!-- 产品网格 -->
      <div v-if="products?.length" class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">
        <AppMediaCard
          v-for="product in products"
          :key="product.id"
          :to="`/products/${product.slug}`"
          :image="product.cover"
          :title="product.name"
          :description="product.summary"
          :tag="product.categoryLabel"
        />
      </div>

      <!-- 空状态 -->
      <EmptyState v-else text="暂无相关产品" />
    </PageSection>
  </div>
</template>
```

**【录屏提示】** 边写边讲。

几个关键点。

**第一，分类筛选用 URL query。** `route.query.category`。**这样筛选状态可以被分享、被收藏、被搜索引擎抓取。** 这是企业站的标准做法，不要用组件内部状态。

**第二，`data-active` + `data-[active]:`。** 我们 4.4 讲的模式，这里直接复用。

**第三，`useFetch` 带 `query`。** 当 query 变化时，Nuxt 会自动重新请求。

**第四，`v-if="products?.length"` 加 `EmptyState`。** 处理空数据情况。**企业项目一定要处理空状态**，不能白屏。

**【录屏提示】** 镜头拉近，语气加重。

**筛选状态同步到 URL，是很多人忽略的细节。** 但它对 SEO、对分享、对返回键体验，都非常重要。

## 四、产品详情页（约 3 分钟）

**【录屏提示】** 新建 `pages/products/[slug].vue`。

```vue
<script setup lang="ts">
import type { Product } from '~/types/product'

const route = useRoute()
const slug = computed(() => route.params.slug as string)

const { data: product } = await useFetch<Product>(`/api/products/${slug.value}`)

if (!product.value) {
  throw createError({ statusCode: 404, statusMessage: '产品不存在' })
}

useSeoMeta({
  title: `${product.value.name} - 某某科技`,
  description: product.value.summary,
  ogImage: product.value.cover,
  ogType: 'product',
})

useHead({
  script: [
    {
      type: 'application/ld+json',
      innerHTML: JSON.stringify({
        '@context': 'https://schema.org',
        '@type': 'Product',
        name: product.value.name,
        description: product.value.summary,
        image: product.value.cover,
      }),
    },
  ],
})
</script>

<template>
  <div>
    <AppBreadcrumb
      :items="[
        { label: '首页', to: '/' },
        { label: '产品中心', to: '/products' },
        { label: product.name },
      ]"
    />

    <section class="py-12">
      <AppContainer>
        <div class="grid grid-cols-1 lg:grid-cols-2 gap-12 items-start">
          <div class="aspect-[4/3] rounded-lg overflow-hidden bg-gray-100">
            <NuxtImg
              :src="product.cover"
              :alt="product.name"
              class="w-full h-full object-cover"
              width="800"
              height="600"
            />
          </div>

          <div>
            <span class="inline-block text-sm font-medium text-brand-500 bg-brand-50 rounded px-3 py-1">
              {{ product.categoryLabel }}
            </span>
            <h1 class="mt-4 text-3xl lg:text-4xl font-display font-bold text-gray-900">
              {{ product.name }}
            </h1>
            <p class="mt-4 text-lg text-gray-600 leading-relaxed">
              {{ product.summary }}
            </p>
            <div class="mt-8 flex gap-4">
              <AppButton size="lg">立即咨询</AppButton>
              <AppButton size="lg" variant="secondary">下载资料</AppButton>
            </div>
          </div>
        </div>

        <div class="mt-16 prose prose-lg max-w-none">
          <div v-html="product.content" />
        </div>
      </AppContainer>
    </section>

    <RelatedProducts :current-id="product.id" />
  </div>
</template>
```

**【录屏提示】** 边写边讲。

几个关键点。

**第一，404 处理。** 产品不存在时 `throw createError`，Nuxt 会自动跳到错误页。**这是标准做法。**

**第二，动态 SEO。** `useSeoMeta` 用产品数据生成 title、description、ogImage。**每个产品都有独立的搜索卡片。**

**第三，结构化数据（JSON-LD）。** 用 `useHead` 注入 Product 类型的 schema。**搜索引擎能识别出这是一个产品页**，可能展示更丰富的搜索结果。

**第四，`prose prose-lg max-w-none`。** Tailwind Typography 插件，让富文本内容有漂亮的排版。**这是企业站渲染富文本的标配。**

**第五，`RelatedProducts` 组件。** 相关产品推荐，增加页面浏览深度。

## 五、关于 `prose`（约 1 分钟）

**【录屏提示】** 镜头拉近，语气放慢。

我单独讲一下 `prose`。

企业站的产品详情、新闻详情，内容往往来自**富文本编辑器**或 **Markdown**。这些 HTML 是"裸的"，没有样式。

Tailwind 的 `prose` 类，能**自动给这些 HTML 加上漂亮的排版**——标题、段落、列表、引用、代码块，全都统一。

用法很简单：给容器加 `prose` 类就行。

**【录屏提示】** 屏幕显示常用修饰。

```html
<div class="prose prose-lg prose-brand max-w-none">
```

- `prose-lg`：大号排版
- `prose-brand`：用品牌色作为链接色
- `max-w-none`：不限制最大宽度（因为我们已经用容器控制了）

**这个插件要单独安装**：`npm install @tailwindcss/typography`，然后在 CSS 里 `@plugin "@tailwindcss/typography";`。

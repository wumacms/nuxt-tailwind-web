# 5.4-新闻_博客页（News）

**【录屏提示】** 开场：讲师出镜，背景为新闻列表和详情页。

---

## 一、开场白（约 30 秒）

好，欢迎回来。

这一节我们做**新闻页**。

新闻页和产品页结构相似，但有**两个独特之处**：

第一，内容通常是**Markdown 驱动**的，需要内容管理系统。

第二，详情页是**阅读型页面**，排版要求更高。

这一节，我们用 **Nuxt Content** 管理内容，做出专业的阅读体验。

---

## 二、为什么用 Nuxt Content（约 1 分 30 秒）

**【录屏提示】** 屏幕显示内容管理方案对比。

新闻内容怎么管理？我讲三种方案。

**方案一，硬编码在代码里。** 最简单，但每次发新闻都要改代码、重新部署。**不推荐。**

**方案二，Headless CMS。** 比如 Strapi、Sanity。功能强，但要单独部署，成本高。

**方案三，Nuxt Content。** 用 Markdown 文件管理内容。**开发友好，版本可控，零外部依赖。**

**【录屏提示】** 镜头切回讲师。

**企业站的中小型新闻模块，Nuxt Content 最合适。** 编辑人员写 Markdown，提交到仓库，自动部署。简单、可靠。

---

## 三、安装与配置 Nuxt Content（约 1 分 30 秒）

**【录屏提示】** 终端安装。

```bash
npm install @nuxt/content
```

然后在 `nuxt.config.ts` 里：

```ts
export default defineNuxtConfig({
  modules: ['@nuxt/content'],
})
```

**【录屏提示】** 新建内容目录。

在项目根目录建 `content/` 文件夹，里面放 Markdown：

```text
content/
└── news/
    ├── 2025-01-01-company-news.md
    └── 2025-02-15-product-launch.md
```

每个文件的 frontmatter 写元信息：

```markdown
---
title: 公司获得年度创新奖
date: 2025-01-01
category: 公司动态
cover: /images/news/award.jpg
excerpt: 我们很荣幸获得本年度行业创新奖...
---

正文内容...
```

## 四、新闻列表页（约 3 分钟）

**【录屏提示】** 新建 `pages/news/index.vue`。

```vue
<script setup lang="ts">
useSeoMeta({
  title: '新闻动态 - 某某科技',
})

const { data: newsList } = await useAsyncData('news-list', () =>
  queryContent('/news')
    .sort({ date: -1 })
    .find()
)
</script>

<template>
  <div>
    <PageHero title="新闻动态" subtitle="了解我们的最新进展" />

    <PageSection>
      <div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">
        <AppMediaCard
          v-for="item in newsList"
          :key="item._path"
          :to="item._path"
          :image="item.cover"
          :title="item.title"
          :description="item.excerpt"
          :tag="item.category"
        />
      </div>
    </PageSection>
  </div>
</template>
```

**【录屏提示】** 边写边讲。

几个关键点。

**第一，`queryContent('/news')`。** 查询 `content/news/` 下的所有文件。

**第二，`.sort({ date: -1 })`。** 按日期倒序。

**第三，`useAsyncData` 包裹。** 给它一个 key，避免重复请求。

**第四，复用 `AppMediaCard`。** 新闻卡和产品卡结构一样，直接复用。

**【录屏提示】** 镜头拉近。

**`item._path` 是 Nuxt Content 自动生成的路径**，直接用作链接。这样你不需要手动维护 URL。

## 五、新闻详情页（约 3 分钟）

**【录屏提示】** 新建 `pages/news/[...slug].vue`。

```vue
<script setup lang="ts">
const route = useRoute()

const { data: article } = await useAsyncData(`news-${route.path}`, () =>
  queryContent(route.path).findOne()
)

if (!article.value) {
  throw createError({ statusCode: 404, statusMessage: '文章不存在' })
}

useSeoMeta({
  title: `${article.value.title} - 某某科技`,
  description: article.value.excerpt,
  ogImage: article.value.cover,
  ogType: 'article',
})
</script>

<template>
  <article>
    <PageSection>
      <AppContainer size="narrow">
        <AppBreadcrumb
          :items="[
            { label: '首页', to: '/' },
            { label: '新闻动态', to: '/news' },
            { label: article.title },
          ]"
        />

        <header class="mt-6">
          <span class="text-sm font-medium text-brand-500">{{ article.category }}</span>
          <h1 class="mt-3 text-3xl lg:text-4xl font-display font-bold text-gray-900 leading-tight">
            {{ article.title }}
          </h1>
          <p class="mt-4 text-sm text-gray-500">
            {{ formatDate(article.date) }}
          </p>
        </header>

        <div class="mt-10 aspect-[16/9] rounded-lg overflow-hidden bg-gray-100">
          <NuxtImg
            :src="article.cover"
            :alt="article.title"
            class="w-full h-full object-cover"
          />
        </div>

        <div class="mt-10 prose prose-lg max-w-none">
          <ContentRenderer :value="article" />
        </div>
      </AppContainer>
    </PageSection>

    <RelatedNews :current-path="route.path" />
  </article>
</template>
```

**【录屏提示】** 边写边讲。

几个关键点。

**第一，`[...slug].vue`。** 这是"通配"动态路由，能匹配多级路径。因为新闻可能有 `/news/2025/01/xxx` 这种结构。

**第二，`queryContent(route.path).findOne()`。** 按路径查单篇文章。

**第三，`<ContentRenderer>`。** 这是 Nuxt Content 的组件，**自动把 Markdown 渲染成 HTML**，并且支持自定义组件。

**第四，阅读型内容用 `AppContainer size="narrow"`。** 我们 3.3 定义的 768px 容器。**太宽的文字读起来累。**

**第五，`prose prose-lg`。** 富文本排版。

**【录屏提示】** 镜头拉近，语气加重。

**注意 `prose` 和 `ContentRenderer` 的配合。** `ContentRenderer` 输出 HTML，`prose` 给它样式。这是 Nuxt Content + Tailwind 的标准组合。

---

## 六、富文本的自定义（约 1 分钟）

**【录屏提示】** 屏幕显示 prose 定制。

`prose` 的默认样式是通用的。要定制成企业风格，用修饰类：

```html
<div class="prose prose-lg prose-brand
            prose-headings:font-display
            prose-headings:text-gray-900
            prose-a:text-brand-500
            prose-img:rounded-lg">
```

**【录屏提示】** 镜头切回讲师。

**`prose-*:` 变体能覆盖任何元素的样式。** 这样你不用写自定义 CSS，就能让富文本符合品牌风格。

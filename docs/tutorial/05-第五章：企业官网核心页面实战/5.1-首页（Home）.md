# 5.1-首页（Home）

**【录屏提示】** 开场：讲师出镜，背景为成品站首页全貌。

---

## 一、开场白（约 30 秒）

好，欢迎来到第五章。

前面四章，我们把地基、骨架、零件都做完了。从这一章开始，我们**真正拼页面**。

第一个页面，也是最重要的页面——**首页**。

首页是企业站的"门面"，用户进来第一眼看到的就是它。它要回答三个问题：**你是谁？你能给我什么？我该做什么？** 这一节，我们不只是写代码，还要讲清楚**首页的设计逻辑**。

---

## 二、首页的结构逻辑（约 2 分钟）

先讲设计思路。

**【录屏提示】** 屏幕显示首页的区块结构图。

企业站的首页，通常按"**转化漏斗**"来组织：

**第一屏，Hero。** 一句话说清"你是谁"，配一个大 CTA。目标是**抓住注意力**。

**第二屏，价值主张。** 3-4 个优势点，回答"为什么选你"。

**第三屏，产品/服务。** 展示核心业务，引导进详情页。

**第四屏，案例/客户。** 用真实案例建立信任。

**第五屏，CTA。** 再次引导行动。

**第六屏，合作伙伴。** logo 墙，增加可信度。

**【录屏提示】** 镜头切回讲师。

**这个顺序不是随便定的。** 它符合用户的认知路径：先知道你是谁，再知道你的价值，再看到证据，最后被引导行动。

**你做首页时，先想清楚每一屏"要达成什么目标"，再想怎么实现。**

## 三、Hero 区实现（约 3 分钟）

好，我们从 Hero 开始。

**【录屏提示】** 新建 `components/sections/HeroSection.vue`。

```vue
<template>
  <section class="relative overflow-hidden bg-gradient-to-b from-brand-50 to-white">
    <AppContainer>
      <div class="grid grid-cols-1 lg:grid-cols-2 gap-12 items-center py-20 lg:py-32">
        <!-- 文案 -->
        <div>
          <span class="inline-block text-sm font-medium text-brand-600 bg-brand-100 rounded-full px-4 py-1.5 mb-6">
            专业企业解决方案
          </span>
          <h1 class="text-4xl lg:text-6xl font-display font-bold text-gray-900 leading-tight">
            用技术驱动<br />
            <span class="text-brand-500">业务增长</span>
          </h1>
          <p class="mt-6 text-lg text-gray-600 leading-relaxed max-w-xl">
            我们为超过 500 家企业提供数字化转型服务，帮助他们提升效率、降低成本、拓展市场。
          </p>
          <div class="mt-8 flex flex-wrap gap-4">
            <AppButton size="lg">免费咨询</AppButton>
            <AppButton size="lg" variant="secondary">查看案例</AppButton>
          </div>
        </div>

        <!-- 插图 -->
        <div class="relative">
          <NuxtImg
            src="/hero-illustration.png"
            alt="产品界面展示"
            class="w-full"
            width="640"
            height="480"
            fetchpriority="high"
          />
        </div>
      </div>
    </AppContainer>
  </section>
</template>
```

**【录屏提示】** 边写边讲。

几个关键点。

**第一，渐变背景。** `bg-gradient-to-b from-brand-50 to-white`，从品牌浅色渐变到白色，视觉上有层次感。

**第二，标签（badge）。** 顶部那个小胶囊，用 `rounded-full`。它起到"定位说明"的作用。

**第三，标题用 `text-4xl lg:text-6xl`。** 手机 36px，桌面 60px。**首屏标题一定要大**，这是视觉重心。

**第四，关键词用品牌色。** "业务增长"用 `text-brand-500`，突出重点。

**第五，`leading-tight`。** 大标题行高要收紧，否则显得松散。

**第六，`fetchpriority="high"`。** Hero 图是首屏关键图，告诉浏览器优先加载。

**【录屏提示】** 镜头拉近，语气加重。

**Hero 的 LCP 优化是重点。** 首屏大图不要懒加载，要预加载、要指定尺寸。**这直接决定你的 Core Web Vitals 分数。**

## 四、价值主张区（约 1 分 30 秒）

**【录屏提示】** 新建 `components/sections/FeatureGrid.vue`。

```vue
<script setup lang="ts">
interface Feature {
  icon: string
  title: string
  description: string
}

defineProps<{ features: Feature[] }>()
</script>

<template>
  <PageSection title="为什么选择我们" subtitle="我们用专业和专注，赢得每一位客户的信任">
    <div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-8">
      <div
        v-for="feature in features"
        :key="feature.title"
        class="text-center p-6 rounded-lg hover:bg-gray-50 transition-colors"
      >
        <div class="inline-flex items-center justify-center w-14 h-14 rounded-full bg-brand-100 text-brand-500 mb-4">
          <Icon :name="feature.icon" class="w-7 h-7" />
        </div>
        <h3 class="text-lg font-semibold text-gray-900">{{ feature.title }}</h3>
        <p class="mt-2 text-sm text-gray-600 leading-relaxed">{{ feature.description }}</p>
      </div>
    </div>
  </PageSection>
</template>
```

**【录屏提示】** 边写边讲。

**第一，用 `PageSection` 承载。** 标题、副标题、间距都交给它，我们只管内容。

**第二，图标用圆形背景包裹。** `w-14 h-14 rounded-full bg-brand-100`，让图标有"底"。

**第三，`hover:bg-gray-50`。** 悬停时轻微变色，增加交互感。

## 五、CTA 区（约 1 分 30 秒）

**【录屏提示】** 新建 `components/sections/CTASection.vue`。

```vue
<template>
  <section class="py-20">
    <AppContainer>
      <div class="relative overflow-hidden rounded-2xl bg-brand-500 px-8 py-16 text-center">
        <h2 class="text-3xl lg:text-4xl font-display font-bold text-white">
          准备好开始了吗？
        </h2>
        <p class="mt-4 text-lg text-brand-100 max-w-2xl mx-auto">
          联系我们，获取专属的解决方案和报价。
        </p>
        <div class="mt-8">
          <AppButton size="lg" variant="secondary">立即咨询</AppButton>
        </div>
      </div>
    </AppContainer>
  </section>
</template>
```

**【录屏提示】** 镜头切回讲师。

**CTA 区的设计要点是"聚焦"。** 深色背景、大标题、单一按钮，把用户的注意力集中到一个动作上。

**注意按钮用了 `secondary`。** 因为在品牌色背景上，用白色按钮对比更明显。

## 六、组装首页（约 1 分钟）

**【录屏提示】** 打开 `pages/index.vue`。

```vue
<script setup lang="ts">
useSeoMeta({
  title: '某某科技 - 专业的企业解决方案提供商',
  description: '我们为超过 500 家企业提供数字化转型服务...',
})

const features = [
  { icon: 'zap', title: '高效交付', description: '...' },
  { icon: 'shield', title: '安全可靠', description: '...' },
  { icon: 'users', title: '专业团队', description: '...' },
]
</script>

<template>
  <div>
    <HeroSection />
    <FeatureGrid :features="features" />
    <ProductShowcase />
    <CaseStudy />
    <CTASection />
    <PartnerLogos />
  </div>
</template>
```

**【录屏提示】** 切浏览器，展示完整首页。

你看，首页就是**区块的堆叠**。每个区块是独立组件，页面只负责"组装"。

**【录屏提示】** 镜头切回讲师。

**这就是组件化的价值。** 首页本身很"薄"，只做编排；复杂逻辑都在区块组件里。

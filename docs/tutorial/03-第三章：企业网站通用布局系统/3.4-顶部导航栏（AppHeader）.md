# 3.4-顶部导航栏（AppHeader）

**【录屏提示】** 开场：讲师出镜，背景为成品站 Header 演示。

---

## 一、开场白（约 30 秒）

好，欢迎回来。

这一节我们做**顶部导航栏**，也就是 Header。

这是企业站**最复杂、也最重要**的布局组件。它要处理：固定定位、滚动变色、移动端汉堡菜单、下拉二级菜单、过渡动画……基本上把前面学的都用上了。

我们分步骤来，从静态到动态，逐步增强。

---

## 二、静态结构（约 2 分钟）

先搭静态结构。

**【录屏提示】** 新建 `components/layout/AppHeader.vue`。

```vue
<template>
  <header class="w-full bg-white border-b border-gray-200">
    <AppContainer>
      <div class="flex items-center justify-between h-16">
        <!-- Logo -->
        <NuxtLink to="/" class="flex items-center gap-2">
          <img src="/logo.svg" alt="Logo" class="h-8" />
          <span class="font-display font-semibold text-lg">某某科技</span>
        </NuxtLink>

        <!-- 导航 -->
        <nav class="hidden md:flex items-center gap-8">
          <NuxtLink to="/" class="text-gray-700 hover:text-brand-500 transition-colors">首页</NuxtLink>
          <NuxtLink to="/about" class="text-gray-700 hover:text-brand-500 transition-colors">关于</NuxtLink>
          <NuxtLink to="/products" class="text-gray-700 hover:text-brand-500 transition-colors">产品</NuxtLink>
          <NuxtLink to="/news" class="text-gray-700 hover:text-brand-500 transition-colors">新闻</NuxtLink>
          <NuxtLink to="/contact" class="text-gray-700 hover:text-brand-500 transition-colors">联系</NuxtLink>
        </nav>

        <!-- 右侧 CTA -->
        <div class="hidden md:block">
          <AppButton variant="primary" size="sm">免费咨询</AppButton>
        </div>
      </div>
    </AppContainer>
  </header>
</template>
```

**【录屏提示】** 边写边讲。

几个关键点。

**第一，`h-16` 固定高度。** 64px，这是企业站 Header 的常见高度。

**第二，`justify-between` 三段式布局。** Logo 在左，导航居中，CTA 在右。

**第三，`hidden md:flex`。** 导航在手机端隐藏，平板及以上显示。这就是我们 2.6
讲的移动优先。

**第四，`hover:text-brand-500 transition-colors`。** hover 变色 +
过渡，细节体验。

## 三、固定定位（约 1 分 30 秒）

**【录屏提示】** 修改 header 的 class。

企业站的 Header 通常要**固定在顶部**，滚动时保持可见。

```html
<header class="fixed top-0 left-0 right-0 z-50 bg-white border-b">
```

**注意，固定定位会让内容被遮挡。** 因为 header 脱离了文档流。所以要在 body 或
main 上加上 padding-top：

**【录屏提示】** 打开 `layouts/default.vue`。

```html
<main class="flex-1 pt-16">
  <slot />
</main>
```

`pt-16` 正好等于 header 的高度。

**【录屏提示】** 镜头拉近。

**或者用 `sticky` 也可以**：`sticky top-0 z-50`。区别是 `sticky`
不脱离文档流，不需要补 padding。

**我个人更推荐 `sticky`**，因为少一个"补
padding"的心智负担，不容易忘。但有些设计需要 `fixed` 的效果，那就用 `fixed`。

## 四、滚动变色（约 2 分钟）

好，接下来做**滚动变色**。就是页面滚下去之后，Header 加个阴影或者变半透明。

**【录屏提示】** 在 script 里写滚动监听。

```vue
<script setup lang="ts">
const scrolled = ref(false)

function onScroll() {
  scrolled.value = window.scrollY > 10
}

onMounted(() => {
  window.addEventListener('scroll', onScroll, { passive: true })
  onScroll()
})

onUnmounted(() => {
  window.removeEventListener('scroll', onScroll)
})
</script>
```

然后绑定到 class：

```html
<header
  class="sticky top-0 z-50 transition-all duration-300"
  :class="scrolled ? 'bg-white/90 backdrop-blur shadow-sm' : 'bg-white'"
>
```

**【录屏提示】** 边写边讲，切浏览器验证。

几个关键点。

**第一，`{ passive: true }`。** 告诉浏览器这个监听器不会调用
`preventDefault`，浏览器可以优化滚动性能。**这是滚动监听必加的。**

**第二，`onMounted` 和 `onUnmounted` 配对。**
组件销毁时要移除监听，否则内存泄漏。

**第三，`window.scrollY`。** 在 SSR 环境下，`window` 不存在。但我们在
`onMounted` 里访问，**此时已经在客户端了，安全。**

**【录屏提示】** 镜头拉近，语气加重。

**SSR 环境下访问 `window`、`document`、`localStorage`，一定要放在 `onMounted`
里，或者用 `import.meta.client` 判断。** 这是 Nuxt 项目最常见的报错来源。

**第四，`bg-white/90 backdrop-blur`。** 半透明白 +
背景模糊，这是现代企业站的常见效果，视觉上更轻盈。

## 五、移动端汉堡菜单（约 2 分 30 秒）

好，现在做**移动端菜单**。

**【录屏提示】** 添加汉堡按钮和抽屉。

```vue
<script setup lang="ts">
const mobileOpen = ref(false)

// 路由变化时关闭菜单
const route = useRoute()
watch(() => route.path, () => {
  mobileOpen.value = false
})
</script>

<template>
  <header class="sticky top-0 z-50 bg-white">
    <AppContainer>
      <div class="flex items-center justify-between h-16">
        <!-- Logo -->

        <!-- 桌面导航 -->
        <nav class="hidden md:flex ...">...</nav>

        <!-- 汉堡按钮（移动端） -->
        <button
          class="md:hidden p-2 -mr-2"
          aria-label="打开菜单"
          @click="mobileOpen = true"
        >
          <Icon name="menu" class="w-6 h-6" />
        </button>
      </div>
    </AppContainer>

    <!-- 移动端抽屉 -->
    <Transition name="drawer">
      <div v-if="mobileOpen" class="fixed inset-0 z-50 md:hidden">
        <div class="absolute inset-0 bg-black/40" @click="mobileOpen = false" />
        <div class="absolute right-0 top-0 bottom-0 w-72 bg-white shadow-xl p-6">
          <button @click="mobileOpen = false">关闭</button>
          <nav class="mt-8 flex flex-col gap-4">
            <NuxtLink to="/">首页</NuxtLink>
            ...
          </nav>
        </div>
      </div>
    </Transition>
  </header>
</template>
```

**【录屏提示】** 边写边讲，切到移动视图验证。

几个关键点。

**第一，`fixed inset-0` 全屏遮罩。** 遮罩层点击关闭菜单。

**第二，抽屉从右侧滑入。** `absolute right-0 w-72`。

**第三，路由变化时自动关闭。** 用 `watch` 监听
`route.path`。这个细节很重要，否则用户点了链接菜单不关。

**第四，`aria-label`。** 无障碍，屏幕阅读器能读出来。

## 六、滚动锁定与焦点管理（约 1 分钟）

**【录屏提示】** 镜头拉近，语气放慢。

两个**容易忽略但很重要**的细节。

**第一，打开菜单时要锁定 body 滚动。**

```ts
watch(mobileOpen, (open) => {
  document.body.style.overflow = open ? "hidden" : "";
});
```

否则菜单开着，背景还能滚，体验很怪。

**第二，焦点管理。**
打开菜单时，焦点应该移到菜单里；关闭时，焦点回到汉堡按钮。这个我们第七章讲 a11y
时再深入。

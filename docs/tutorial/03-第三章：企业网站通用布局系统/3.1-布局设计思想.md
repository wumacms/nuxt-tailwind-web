## 二、为什么需要"布局系统"（约 2 分钟）

先讲清楚问题的本质。

**【录屏提示】** 屏幕显示两个网站的对比：左边间距混乱，右边整齐统一。

我们看这两张图。左边这个站，每个页面的左右边距都不一样，有的 20px、有的 40px、有的 60px。区块之间的间距也忽大忽小。

右边这个站，所有页面都是**同样的容器宽度、同样的边距、同样的间距节奏**。看起来就专业。

**【录屏提示】** 镜头切回讲师。

差别在哪？**差在有没有"布局系统"。**

布局系统是什么？简单说，就是**一套统一的规则**，规定：

- 内容区最宽多少
- 左右留白多少
- 区块之间间距多少
- 栅格怎么分

有了这套规则，你写任何页面都是**在同一套框架里填内容**，而不是每次重新发明。

**【录屏提示】** 镜头拉近，语气加重。

**这对企业站尤其重要**，因为企业站页面多、迭代久、经常换人维护。没有系统，三个月后就是一团乱麻。

---

## 三、布局的三要素（约 3 分钟）

那布局系统具体包含什么？我总结成**三要素**：容器、栅格、间距。

**【录屏提示】** 屏幕逐个显示三要素。

### 要素一：容器（Container）

容器解决的是"**内容区最宽多少、怎么居中**"的问题。

企业站的典型做法是：**内容区有一个最大宽度**，比如 1280px；**超过这个宽度就居中，左右留白**。

为什么要有最大宽度？

因为在大屏上，如果文字从屏幕最左拉到最右，**阅读体验极差**。人眼扫视一行超过 100 个字符就会累。所以内容区要收窄。

**【录屏提示】** 拖动浏览器宽度，展示容器居中效果。

你看，这就是容器的效果。屏幕再宽，内容区也不会无限拉伸。

### 要素二：栅格（Grid）

栅格解决的是"**内容怎么分列**"的问题。

企业站常见的是 12 列栅格，或者简化的 2 列、3 列、4 列。

栅格的价值是：**让不同区块的对齐关系一致**。比如上面的卡片是 3 列，下面的图文也是 3 列，视觉上就对得齐。

### 要素三：间距（Spacing）

间距解决的是"**区块之间留多少空**"的问题。

这里的关键是**节奏感**。企业站的区块间距，通常是固定的几档：比如区块之间 80px，区块内元素之间 24px，标题和正文之间 16px。

**【录屏提示】** 镜头切回讲师。

**间距是布局里最容易被忽略、但最影响观感的。** 一个站看起来"高级"还是"廉价"，很大程度取决于间距是否统一、是否有节奏。

## 四、从设计稿拆解布局（约 2 分 30 秒）

好，理论讲完，我们拿设计稿来实操一遍。

**【录屏提示】** 切到 Figma，打开企业站首页设计稿。

我现在看这张首页设计稿，我要从里面**提取出布局规则**。

**第一步，看容器。** 内容区从哪到哪？

我量一下——设计稿宽度是 1440px，内容区左右各留 80px，所以**内容区最大宽度是 1280px**。

**第二步，看栅格。** 产品卡片区是几列？

数一下——桌面端 3 列，卡片之间有间距。量一下间距，是 24px。

**第三步，看间距。** 区块之间留多少？

Hero 区到下面的优势区，量一下，是 96px。优势区到案例区，也是 96px。**所以区块间距是 96px。**

区块内部：标题到副标题 16px，副标题到内容 32px。

**【录屏提示】** 镜头切回讲师。

好，我们现在**从一张设计稿里，提取出了三条布局规则**：

- 容器最大宽度 1280px
- 卡片 3 列，间距 24px
- 区块间距 96px，内部间距有 16/32 两档

**这些规则，就是我们的布局系统。** 接下来所有页面，都遵守这套规则。

**【录屏提示】** 镜头拉近，语气加重。

**注意，这套规则不是拍脑袋定的，是从设计稿里"读"出来的。** 这是开发和设计协作的关键——**你要能从设计稿里提取出可复用的规则，而不是一页一页照着抄。**

## 五、布局系统怎么落地（约 1 分 30 秒）

好，提取出规则之后，怎么落到代码里？

**【录屏提示】** 屏幕显示映射关系。

我的做法是**分三层落地**：

**第一层，令牌层。** 把布局相关数值写进 `@theme`：

```css
@theme {
  --container-page: 1280px;
  --spacing-section: 6rem;   /* 96px */
  --spacing-block: 2rem;     /* 32px */
}
```

**第二层，组件层。** 封装布局组件，比如 `<AppContainer>`、`<PageSection>`。

**第三层，页面层。** 页面里只用布局组件，不直接写宽度和间距。

**【录屏提示】** 镜头切回讲师。

**这就是"系统化"的思路**：把规则沉淀到令牌和组件里，页面只负责"填内容"。

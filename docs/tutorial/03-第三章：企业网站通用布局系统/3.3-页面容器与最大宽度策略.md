# 3.3-页面容器与最大宽度策略

**【录屏提示】** 开场：讲师出镜，背景为不同宽度的浏览器窗口。

---

## 一、开场白（约 30 秒）

好，欢迎回来。

上一节我们搭好了布局骨架。这一节，我们做**第一个真正意义上的布局组件**——**页面容器**。

你可能会想："容器不就是 `max-w-7xl mx-auto` 吗，有什么好讲的？"

有。因为**容器是企业站一致性的第一道防线**。这一节，我们把它封装成一个组件，支持多种宽度变体，全站统一调用。

---

## 二、为什么不直接用 Tailwind 的 container（约 1 分 30 秒）

Tailwind 其实自带一个 `container` 类。为什么不用它？

**【录屏提示】** 屏幕显示 Tailwind container 的行为。

`container` 的作用是"在小屏幕上 100% 宽，在断点处固定宽度"。它的行为是**跟断点挂钩**的。

但企业站要的往往是：**内容区最大宽度固定，超过就居中。** 这个用 `container` 反而不好控制。

**【录屏提示】** 镜头切回讲师。

而且，企业站往往需要**多种容器**：

- 普通页面：1280px
- 阅读型内容（新闻详情）：768px，太宽不好读
- 全宽区块（比如 Hero）：铺满
- 窄内容（比如 404）：640px

所以我们需要一个**可配置的容器组件**，而不是一个固定的类。

---

## 三、封装 AppContainer（约 4 分钟）

好，我们来写。

**【录屏提示】** 新建 `components/layout/AppContainer.vue`。

```vue
<script setup lang="ts">
type Size = 'narrow' | 'default' | 'wide' | 'full'

interface Props {
  size?: Size
  as?: string
}

const props = withDefaults(defineProps<Props>(), {
  size: 'default',
  as: 'div',
})

const sizeClasses: Record<Size, string> = {
  narrow: 'max-w-3xl',      // 768px
  default: 'max-w-7xl',     // 1280px
  wide: 'max-w-[1600px]',   // 1600px
  full: 'max-w-none',       // 不限
}
</script>

<template>
  <component
    :is="as"
    :class="['mx-auto px-4 md:px-6 lg:px-8', sizeClasses[size]]"
  >
    <slot />
  </component>
</template>
```

**【录屏提示】** 边写边讲，逐段解释。

好，我解释几个设计点。

**第一，`size` 用联合类型。** 限定只能选四种之一，TS 会检查。如果你写错了，编辑器当场报错。

**第二，`sizeClasses` 映射表。** 每个尺寸对应一个 `max-w-*` 类。注意 `full` 用 `max-w-none`，表示不限制最大宽度。

**第三，`mx-auto` 负责居中。** 内容区超过最大宽度时，左右自动平分剩余空间。

**第四，`px-*` 是响应式内边距。** 手机上 `px-4`（16px），平板上 `px-6`（24px），桌面 `px-8`（32px）。这样小屏幕不挤，大屏幕不空。

**第五，`as` prop 让容器可以是任意标签。** 默认是 `div`，但你也可以传 `section`、`article`、`header`。用 `<component :is>` 动态渲染。

**【录屏提示】** 镜头拉近，语气加重。

**这个"多态组件"模式很实用。** 它让组件既能承载结构，又能保持语义化。企业站做 SEO 时，语义化标签很重要。

## 四、把容器宽度写进令牌（约 1 分 30 秒）

好，上一节我们讲了"把规则沉淀到令牌"。容器的宽度，也应该进令牌。

**【录屏提示】** 打开 `theme.css`。

```css
@theme {
  --container-page: 1280px;
  --container-narrow: 768px;
  --container-wide: 1600px;
}
```

然后在组件里用：

```ts
const sizeClasses: Record<Size, string> = {
  narrow: 'max-w-(--container-narrow)',
  default: 'max-w-(--container-page)',
  wide: 'max-w-(--container-wide)',
  full: 'max-w-none',
}
```

**【录屏提示】** 镜头切回讲师。

**注意 V4 的写法：`max-w-(--container-page)`。** 这是 V4 引用 CSS 变量的语法——用括号包住变量名。

这样做的好处是：**宽度值集中在令牌里。** 哪天设计说"内容区改成 1440"，你只改令牌，全站生效。

## 五、在页面里使用（约 1 分 30 秒）

**【录屏提示】** 打开一个页面，写示例。

```vue
<template>
  <AppContainer>
    <h1>页面标题</h1>
    <p>内容...</p>
  </AppContainer>
</template>
```

或者指定尺寸：

```vue
<AppContainer size="narrow">
  <!-- 新闻正文 -->
</AppContainer>
```

**【录屏提示】** 切浏览器，展示效果。

你看，这就是容器的效果。不同尺寸的内容区，都居中，都有合理的左右留白。

## 六、一个常见问题：嵌套容器（约 1 分钟）

**【录屏提示】** 镜头拉近，语气放慢。

这里有个**容易踩的坑**：**容器不要嵌套。**

如果你在 `default` 容器里又放了一个 `default` 容器，内部的会因为 `max-w` 限制而变窄，`px` 也会叠加，导致内容缩得不对。

**规则是：一个页面区块，只用一个容器。** 容器内部如果需要分列，用栅格（grid/flex），不要再套容器。

如果你确实需要不同的宽度，那就用 `size` 参数，而不是嵌套。

**第八章，工程化与性能。** 类名规范、冲突解决、体积、性能、缓存、部署。**这是"能上线、能维护"。**

**第九章，综合与复盘。** 完整流程演示、踩坑清单、团队协作、总结。**这是"融会贯通"。**

# 二、课程答疑区 FAQ 文档

## 2.1 使用说明

本文档用于**课程答疑区置顶**，包含**高频问题 + 标准答案**。学员提问前先看这里，能解决 80% 的疑问。

---

## 2.2 环境与安装

**Q1：Node 版本要求？**

A：Node 18 以上，**推荐 20 LTS**。用 `node -v` 检查。低于 18 会报错。

**Q2：`npx nuxi init` 卡住不动？**

A：网络问题。可以：

1. 挂代理
2. 用 `npm config set registry https://registry.npmmirror.com` 换淘宝源
3. 手动 clone starter 仓库

**Q3：安装 Tailwind 时报错？**

A：确认命令是 `npm install tailwindcss @tailwindcss/vite`。**V4 不需要 `postcss` 和 `autoprefixer`**，如果装了反而可能冲突。

**Q4：样式完全不生效？**

A：按顺序检查：

1. `nuxt.config.ts` 的 `css` 字段路径对不对
2. `main.css` 里有没有 `@import "tailwindcss"`
3. `vite.plugins` 里有没有 `tailwindcss()`
4. **重启 dev server**（改配置后必须重启）

---

## 2.3 Tailwind V4 相关

**Q5：V4 和 V3 最大的区别？**

A：三个：

1. **配置文件没了**，改用 `@theme` 写在 CSS 里
2. **`content` 字段没了**，自动检测
3. **默认边框色变成 `currentColor`**（V3 是灰色）

**Q6：`@theme` 和 `:root` 变量有什么区别？**

A：`@theme` 定义的变量，**Tailwind 会自动生成工具类**（如 `--color-brand-500` → `bg-brand-500`）。`:root` 只是普通 CSS 变量，不生成工具类。

**Q7：为什么我写的类没生成？**

A：**90% 是动态拼接。** 比如 `` `text-${color}-500` ``，Tailwind 扫不到。改用**完整类名映射表**。

**Q8：`@apply` 能用吗？**

A：能，但**慎用**。优先抽组件。`@apply` 只用于覆盖第三方样式。

**Q9：`@utility` 和 `@layer utilities` 的区别？**

A：`@utility` 定义的类**可以被变体修饰**（`md:text-balance`）。`@layer utilities` 不行。**V4 推荐 `@utility`。**

---

## 2.4 Nuxt 相关

**Q10：`window is not defined` 怎么解决？**

A：SSR 环境下没有 `window`。解决：

1. 放在 `onMounted` 里
2. 用 `if (import.meta.client)` 判断
3. 用 `<ClientOnly>` 包裹组件

**Q11：`useFetch` 和 `$fetch` 什么时候用？**

A：**取数据用 `useFetch`，提交动作用 `$fetch`。** 事件处理里发请求也用 `$fetch`。

**Q12：`await useFetch` 和 `useLazyFetch` 的区别？**

A：

- `await useFetch`：**等待数据**再渲染，数据进 HTML
- `useLazyFetch`：**不等待**，先渲染，数据后到

**首屏关键数据用 `await`，非关键用 `Lazy`。**

**Q13：`routeRules` 配了 `isr` 不生效？**

A：检查部署环境。**纯静态托管不支持 `isr` 和 `swr`。** 需要 Node 服务或支持边缘渲染的平台。

**Q14：`error.vue` 里 `navigateTo` 不生效？**

A：错误状态下路由是锁的，**要用 `clearError({ redirect: '/' })`**。

---

## 2.5 样式与设计

**Q15：暗色模式闪烁怎么解决？**

A：用**内联脚本**在页面渲染前设置 `dark` 类。见 7.2 节。**脚本必须内联**，不能放外部文件。

**Q16：组件样式被外部 class 覆盖不了？**

A：引入 `tailwind-merge`：

```ts
import { twMerge } from 'tailwind-merge'
const classes = twMerge('bg-brand-500', props.class)
```

**Q17：`columns` 布局行间距不对？**

A：`gap` 只管列间距。**行间距要用 `mb-*`。**

**Q18：图片导致页面跳动（CLS）？**

A：**`width` 和 `height` 必填。** 用 `NuxtImg` 并指定尺寸。

**Q19：首屏图加载慢（LCP 差）？**

A：**首屏图不要 `loading="lazy"`。** 用 `preload` + `fetchpriority="high"`。

---

## 2.6 部署与上线

**Q20：环境变量为什么会泄漏？**

A：**`NUXT_PUBLIC_` 前缀的变量会被打包进客户端代码。** 密钥不要加这个前缀。

**Q21：部署到静态托管，SSR 页面打不开？**

A：静态托管只能跑 SSG。**要 SSR 必须部署到 Node 服务或 Serverless。**

**Q22：CI/CD 构建失败，本地正常？**

A：检查：

1. Node 版本是否一致
2. 环境变量是否配置
3. `npm ci` vs `npm install` 的差异
4. `.env` 是否提交（不该提交）

A：看 9.4 节的进阶方向。**建议选一个方向做小项目**，比如 i18n 或组件库抽包。

**Q24：看不懂某段代码怎么办？**

A：三步：

2. 用 `git diff` 看和你代码的差异

**Q25：课程代码能商用吗？**

A：**组件库和工程模板可以用于你的项目**，但**不要直接转卖课程内容**。

3. 必要时 1 对 1 辅导
4. **不要公开争论**

**场景二：学员要求退款。**

**处理**：

1. 了解原因
2. 能解决就解决（换版本、延期）
3. 不能解决就按平台规则退款
4. **态度要好**，退款也是口碑

**场景三：群里出现广告/负面。**

**处理**：

1. 及时撤回
2. 私聊警告
3. 屡教不改移出群

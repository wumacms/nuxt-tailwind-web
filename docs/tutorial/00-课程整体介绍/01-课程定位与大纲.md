# 课程定位与大纲

## 课程定位

**不是** Nuxt 教程、**不是** TypeScript 教程、**不是** TailwindCSS 文档复述课。

**而是**一门以"企业官网"为载体的**综合实战课**：用真实项目驱动，讲清楚
TailwindCSS V4 在 Nuxt + TS
工程中如何落地、如何组织、如何与设计协作、如何应对企业级需求。

> 相比 Vue3 版本，Nuxt 版本额外强化：**SEO 与
> SSR/SSG**、**文件路由与布局系统**、**服务端能力（表单/接口）**、**内容管理（可选）**
> —— 这些正是企业官网最关心的能力。

## 课程特色说明

1. **以 TailwindCSS 为主线**：Nuxt 和 TS 是"载体"，重点讲 Tailwind
   在真实工程中怎么用、怎么组织、怎么和设计协作。
2. **以企业官网为场景**：所有知识点都落在真实页面上，不做孤立 Demo。
3. **发挥 Nuxt 的独有价值**：SEO、SSR/SSG、文件路由、服务端能力、内容管理——这是
   Vue3 版本无法覆盖、而企业官网恰恰最需要的部分。
4. **讲思想而非语法**：每个技术点都回答"为什么这么做""什么时候不该这么做"。
5. **完整交付链路**：从设计稿 → 组件 → 页面 → SEO → 优化 → 部署，走通全流程。
6. **可复用资产**：课程产出一套企业站组件库 + 设计令牌体系 + Nuxt
   工程模板，学员可直接用于工作。

## 与 Vue3 版本的核心差异对比

| 维度     | Vue3 版本            | Nuxt 版本                         |
| -------- | -------------------- | --------------------------------- |
| 路由     | 手动配置 vue-router  | 文件路由约定                      |
| 布局     | 手动封装 Layout 组件 | 内置 Layouts 机制                 |
| SEO      | 需自行处理           | `useSeoMeta` / `useHead` 原生支持 |
| 渲染     | SPA 为主             | SSR / SSG / ISR / 混合渲染        |
| 数据     | 自行封装请求         | `useFetch` / `useAsyncData`       |
| 服务端   | 无                   | `server/api` 一体化               |
| 内容管理 | 自行集成             | Nuxt Content / CMS 生态           |
| 部署     | 静态托管             | Nitro 多目标部署                  |

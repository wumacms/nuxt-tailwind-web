## 一、开场白（约 30 秒）

好，欢迎回来。

这一节我们讲 **TypeScript 和 Tailwind 怎么配合**。

有同学可能会问："Tailwind 不就是写类名吗，跟 TS 有什么关系？"

关系大了。**当你用 TS 给组件的样式接口做约束时，你能在编译期就发现问题，而不是等用户点了才发现样式错了。**

这一节，我们讲三个层次：变体类型、类名映射、props 设计。

---

## 二、变体类型：联合类型约束（约 2 分 30 秒）

我们先从最基础的开始。

**【录屏提示】** 在组件里写类型定义。

假设我们做按钮，它有几个变体：

```ts
type ButtonVariant = 'primary' | 'secondary' | 'danger' | 'ghost'
type ButtonSize = 'sm' | 'md' | 'lg'
```

这是**联合类型**。它的作用是：**限定取值范围。**

**【录屏提示】** 在模板里用这个类型，故意写错，展示 IDE 报错。

```vue
<script setup lang="ts">
defineProps<{
  variant?: ButtonVariant
  size?: ButtonSize
}>()
</script>
```

现在如果你写 `<AppButton variant="primry">`（拼错了），编辑器**当场标红**。

**【录屏提示】** 镜头拉近。

这就是 TS 的价值：**把"用户点击时才发现"的错误，提前到"写代码时"。**

---

## 三、类名映射表：类型安全的关键（约 3 分钟）

好，有了类型，接下来是**把类型映射到类名**。

**【录屏提示】** 在 script 里写映射表。

```ts
const variantClasses: Record<ButtonVariant, string> = {
  primary: 'bg-brand-500 text-white hover:bg-brand-600',
  secondary: 'bg-gray-100 text-gray-900 hover:bg-gray-200',
  danger: 'bg-red-500 text-white hover:bg-red-600',
  ghost: 'bg-transparent text-brand-500 hover:bg-brand-50',
}
```

这里有几个关键点。

**第一，`Record<ButtonVariant, string>` 这个类型。** 它表示"一个对象，key 是 ButtonVariant 的所有取值，value 是字符串"。

**好处是**：如果你漏了任何一个 variant，TS 会报错。比如你忘了写 `ghost`，编辑器会说"类型不完整"。

**第二，值必须是完整的类名字符串。**

你看 `'bg-brand-500 text-white hover:bg-brand-600'`，这是**完整的字面量**。Tailwind 扫描源码时能扫到，能生成。

**【录屏提示】** 镜头拉近，语气加重。

**这一点非常重要**。它同时满足两个需求：**TS 类型安全 + Tailwind 能扫到。**

如果你写成 `bg-${variant}-500`，两边都满足不了。所以我们 2.3 讲的坑，在 TS 这里也有对应解法——**用映射表。**

**第三，`as const` 的进阶用法。**

如果你想让 TS 推断出更精确的类型，可以加 `as const`：

```ts
const variantClasses = {
  primary: '...',
  secondary: '...',
} as const
```

这样 TS 会把每个 value 当成字面量类型，而不是 `string`。一般用不上，但知道有这回事。

## 四、组合多个变体（约 2 分钟）

好，一个组件往往有多个变体维度。比如按钮既有 variant，又有 size。

**【录屏提示】** 写多维度映射。

```ts
const sizeClasses: Record<ButtonSize, string> = {
  sm: 'px-3 py-1 text-sm',
  md: 'px-4 py-2 text-base',
  lg: 'px-6 py-3 text-lg',
}
```

然后模板里组合：

```vue
<template>
  <button :class="[variantClasses[variant], sizeClasses[size]]">
    <slot />
  </button>
</template>
```

`:class` 接受数组，数组里每一项都是完整的类名字符串。**Tailwind 全部能扫到。**

**【录屏提示】** 镜头切回讲师。

**这个模式，我们后面做所有组件都会用。** 你把它记住。

## 五、props 的类型设计（约 1 分 30 秒）

最后讲一下 **props 的类型设计**。

**【录屏提示】** 打开一个组件，展示 props 定义。

```ts
interface Props {
  variant?: ButtonVariant
  size?: ButtonSize
  disabled?: boolean
  loading?: boolean
}

const props = withDefaults(defineProps<Props>(), {
  variant: 'primary',
  size: 'md',
  disabled: false,
  loading: false,
})
```

这里有几个**设计思想**。

**第一，可选 props 给默认值。** 用 `withDefaults` 设置默认值，这样调用方不传也能正常工作。

**第二，用 `?` 标记可选。** 对使用方友好，不需要每次都传全部。

**第三，类型要精确。** `disabled` 是 `boolean`，不是 `string`。`variant` 是联合类型，不是 `string`。

**【录屏提示】** 镜头拉近。

**精确的类型 = 好的文档。** 别人看你的 props 定义，就知道怎么用。

## 一、开场白（约 1 分钟）

好，欢迎来到《使用 Nuxt + TailwindCSS V4 + TypeScript 开发企业网站实战教程》。

我是这门课的讲师。在正式开始之前，我想先花几分钟，把这门课**到底是什么、不是什么、学完你能得到什么**，讲清楚。因为现在市面上的前端课程太多了，我不想让你带着错误的预期进来，学到一半发现"这不是我要的"。

**【录屏提示】** 镜头略微拉近，语气放慢。

先说**这门课不是什么**。

它不是 Nuxt 语法课。我不会花大段时间去讲 `useFetch` 有多少个参数、`definePageMeta` 有哪些选项。这些你查文档就有，而且文档永远比我讲得新。

它也不是 TypeScript 教程。我不会从"什么是接口、什么是泛型"开始讲。TS 在这门课里是**工具**，不是**主题**。

它更不是 TailwindCSS 文档的复述。我不会把官网的类名一个一个念给你听。

**【录屏提示】** 切到最终成品站，快速滚动展示。

那**这门课是什么**？

一句话：**我们用一个真实的企业官网项目，把 Nuxt、TailwindCSS V4、TypeScript 这三样东西，真正地综合起来用一遍。**

重点在"综合"两个字。因为真实工作里，难点从来不是"某个 API 怎么用"，而是**"这个需求我该用什么方案、怎么组织代码、怎么和设计协作、怎么保证三个月后还能维护"**。

这才是这门课要教的东西。

## 二、最终成品演示（约 3 分钟）

好，我们先看看学完这门课，你会做出一个什么样的东西。

**【录屏提示】** 切到浏览器，全屏展示成品站。开始逐页走查。

这是首页。顶部是一个固定导航栏，滚动的时候会变色。往下是 Hero 区，左边文案右边插图。再往下是产品优势、案例展示、CTA 按钮、合作伙伴 logo 墙。

注意看，我现在把窗口缩小——**整个页面是响应式的**，从桌面四列变成平板两列，再变成手机单列，导航栏收成了汉堡菜单。

**【录屏提示】** 拖动浏览器窗口宽度，展示响应式变化。

我们继续看产品页。这里是列表，有分类筛选。点进任意一个产品——注意 URL 变了，是 `products/xxx` 这种动态路由。详情页有独立的 SEO 标题和描述。

**【录屏提示】** 打开 DevTools，查看详情页的 meta 标签。

你看，`title`、`description`、`og:image` 都是动态生成的。这就是 Nuxt 在企业站场景下的核心价值——**搜索引擎能正确抓取每个页面**。

我们再看新闻页。这里是 Markdown 驱动的内容，富文本排版用的是 Tailwind Typography。点进去，正文的标题、段落、引用、代码块，全都是统一风格。

然后是联系我们。这是一个表单，提交之后会走服务端接口，有校验、有 loading、有成功提示。

**【录屏提示】** 演示表单提交，展示 Toast 提示。

最后我们看错误页。我随便输一个不存在的地址——你看，这不是默认的 404，是我们自己设计的品牌化错误页。

**【录屏提示】** 访问一个不存在的路由，展示自定义 error 页。

好，这就是我们整门课的最终目标。**一个完整的、可上线的、企业级别的官网。**

## 三、学习路径与知识地图（约 3 分钟）

那这个成品，我们是怎么一步步做出来的？我讲一下课程的整体结构。

**【录屏提示】** 切到课程大纲图（思维导图形式）。

整门课分成九章。

**第一章**，就是我们现在在的这一章，做开篇和项目总览，把环境和架构搭起来。

**第二章**，是核心中的核心——**TailwindCSS V4 在 Nuxt 工程里怎么落地**。包括 `@theme` 定制设计令牌、类名怎么组织、响应式怎么做。

**第三章**，我们做**通用布局系统**。导航栏、页脚、侧边栏、面包屑，这些是全站复用的骨架。

**第四章**，做**核心 UI 组件**。按钮、表单、卡片、弹窗、表格，做成一套组件库。

**第五章**，进入**页面实战**。首页、关于、产品、新闻、案例、联系，一个页面一个页面地实现。

**第六章**，是 Nuxt 的专属强化——**SEO、内容管理和数据获取**。这是企业站最值钱的部分。

**第七章**，讲**设计系统和主题化**。包括暗色模式、多品牌主题、动效、可访问性。

**第八章**，讲**工程化和性能优化**。类名规范、构建体积、首屏优化、缓存策略、部署上线。

**第九章**，是**综合复盘**。我会拿一张全新的设计稿，从零到一完整实现一遍，串起前面所有知识。

**【录屏提示】** 镜头切回讲师。

你可以看到，这个结构是**层层递进**的：先打地基（令牌），再搭骨架（布局），再做零件（组件），然后组装（页面），最后优化和交付。

每一章都建立在前一章之上，不是零散的知识点堆砌。

## 四、前置要求与心态建议（约 2 分钟）

好，最后讲讲**学这门课你需要什么基础**。

**【录屏提示】** 屏幕显示前置知识清单。

第一，**你要会 Vue 3 的基础**。知道组件、props、插槽、组合式 API 是怎么回事。如果你完全没接触过 Vue，建议先补一下基础再来。

第二，**你要会 CSS 基础**。知道 Flexbox、Grid、定位、盒模型。Tailwind 是 CSS 的工具，不是替代品。

第三，**TypeScript 会一点就行**。知道类型、接口、泛型大概是什么概念。课程里遇到 TS 的地方，我会解释为什么要这么写，但不会停下来教你语法。

第四，**对 Nuxt 完全没经验也没关系**。这门课会带你从零初始化项目。当然，如果你用过 Nuxt，会理解得更快。

**【录屏提示】** 镜头切回讲师，语气真诚。

最后我想说一句**心态上的建议**。

这门课的重点是"**思路**"。每一个技术决策，我都会尽量回答两个问题：**为什么这么做？什么情况下不该这么做？**

所以你在看的时候，不要只是抄代码。你要想：如果换成我的项目，我会怎么选？

好，那我们就正式开始。下一节，我们聊一个很多人忽略、但其实特别重要的问题——**为什么企业站要选 Nuxt，而不是纯 Vue3？**

## 二、环境检查（约 1 分钟）

好，第一步，检查环境。

**【录屏提示】** 在终端依次执行命令。

```bash
node -v
npm -v
```

我这边 Node 是 20 版本。**建议你用 Node 18 以上**，Nuxt 3 官方要求最低是 18。

如果你用的是 `nvm` 或者 `fnm` 管理 Node 版本，可以切一下。

```bash
nvm use 20
```

版本对了，我们就开始。

## 三、初始化 Nuxt 项目（约 2 分 30 秒）

**【录屏提示】** 在终端执行初始化命令。

我们用官方的初始化命令：

```bash
npx nuxi@latest init enterprise-site
```

回车之后，它会问你几个问题。

第一个是包管理器，我选 `npm`。你用 pnpm 或 yarn 也行，选你顺手的。

然后它会问要不要初始化 git 仓库，选 yes。

**【录屏提示】** 等待安装完成，展示目录结构。

好，安装完成。我们进目录看一下：

```bash
cd enterprise-site
ls -la
```

你会看到 Nuxt 帮我们生成的基础结构。有 `nuxt.config.ts`、`app.vue`、`package.json` 这些。

**【录屏提示】** 打开 `package.json`。

我特别提一句：Nuxt 默认就带 TypeScript 支持，`tsconfig.json` 也是自动生成的。我们**不需要额外配置 TS**。

先启动一下，确认项目能跑：

```bash
npm run dev
```

**【录屏提示】** 浏览器打开 `http://localhost:3000`，展示 Nuxt 欢迎页。

好，看到这个欢迎页，说明基础项目 OK 了。

---

## 四、安装 TailwindCSS V4（约 3 分钟）

接下来是重点——**安装 TailwindCSS V4**。

这里我要特别强调一下，**V4 的安装方式和 V3 完全不一样**。如果你在网上搜到的教程还是让你装 `tailwindcss postcss autoprefixer` 然后跑 `npx tailwindcss init`，那是 V3 的老方法，**V4 不需要这些**。

**【录屏提示】** 切到终端，先停止 dev server（Ctrl+C）。

好，先停掉服务。然后执行：

```bash
npm install tailwindcss @tailwindcss/vite
```

注意，V4 的官方推荐方式是**用 Vite 插件**，也就是 `@tailwindcss/vite`。因为 Nuxt 底层就是 Vite，所以这个插件能直接用。

**【录屏提示】** 打开 `nuxt.config.ts`，边写边讲。

安装完，我们配置 `nuxt.config.ts`：

```ts
import tailwindcss from '@tailwindcss/vite'

export default defineNuxtConfig({
  compatibilityDate: '2024-11-01',
  devtools: { enabled: true },
  vite: {
    plugins: [tailwindcss()],
  },
})
```

这里我把 `tailwindcss()` 插件加到 Vite 的 plugins 里。

**【录屏提示】** 镜头拉近，语气放慢，这是重点。

**注意，V3 时代你需要 `postcss.config.js` 和 `tailwind.config.js`，V4 这两个文件都不需要了。** 如果你看到项目里还有这两个文件，那可能是旧版本残留，建议删掉。

这也是为什么 V4 更简洁——**配置全部收敛到 CSS 里**。

---

## 五、引入 Tailwind 样式（约 2 分钟）

好，插件装好了，接下来要**引入 Tailwind 的样式**。

**【录屏提示】** 新建 `assets/css/main.css`。

我们在 `assets/css/` 下新建一个文件，叫 `main.css`。写入：

```css
@import "tailwindcss";
```

就这一行。这是 V4 的入口写法。V3 时代要写三行 `@tailwind base; @tailwind components; @tailwind utilities;`，**V4 用一行 `@import` 就搞定了**。

**【录屏提示】** 打开 `nuxt.config.ts`。

然后我们把它注入到 Nuxt 配置里：

```ts
export default defineNuxtConfig({
  compatibilityDate: '2024-11-01',
  devtools: { enabled: true },
  css: ['~/assets/css/main.css'],
  vite: {
    plugins: [tailwindcss()],
  },
})
```

注意 `css` 这个字段，路径用 `~/` 开头，表示项目根目录。

## 六、验证是否生效（约 1 分钟）

好，我们验证一下。

**【录屏提示】** 打开 `app.vue`，替换内容。

把 `app.vue` 改成：

```vue
<template>
  <div class="min-h-screen bg-gray-100 flex items-center justify-center">
    <h1 class="text-4xl font-bold text-blue-600">
      Tailwind 生效了
    </h1>
  </div>
</template>
```

**【录屏提示】** 终端运行 `npm run dev`，浏览器打开。

你看，背景变灰了，文字变蓝变大了，居中显示了。**说明 Tailwind V4 已经成功接入 Nuxt。**

---

## 七、几个配置坑（约 1 分钟）

最后，我讲几个**常见的坑**。

**【录屏提示】** 屏幕显示注意事项清单。

**第一个坑**：如果你看到样式没生效，先检查 `nuxt.config.ts` 里 `css` 字段路径对不对。`~` 是别名，指向项目根。

**第二个坑**：V4 的 `@import "tailwindcss"` 必须放在 CSS 文件的**最顶部**，前面不能有其他规则，否则会报错。

**第三个坑**：如果你同时装了 V3 的 Tailwind，可能会冲突。确认 `package.json` 里 `tailwindcss` 版本是 4.x。

**第四个坑**：修改 `nuxt.config.ts` 后，有时候需要重启 dev server 才生效。

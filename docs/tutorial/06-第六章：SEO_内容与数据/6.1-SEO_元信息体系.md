## 二、SEO 元信息是什么（约 1 分 30 秒）

**【录屏提示】** 屏幕显示一段 HTML 的 `<head>`。

SEO 元信息，就是网页 `<head>` 里的那些标签：`<title>`、`<meta name="description">`、`<link rel="canonical">` 等等。

它们**不显示在页面上**，但搜索引擎和社交平台靠它们理解你的页面。

**【录屏提示】** 屏幕显示搜索结果卡片。

你看这个 Google 搜索结果：蓝色的标题、下面的描述、中间的 URL。**这些内容就来自元信息。**

**元信息写得好，点击率就高。** 这是企业站 SEO 的第一道门槛。

## 三、`useSeoMeta` 与 `useHead`（约 3 分钟）

Nuxt 提供两个 API 来管理元信息：`useSeoMeta` 和 `useHead`。

**【录屏提示】** 屏幕对比两个 API。

**`useSeoMeta`** 专门用于 SEO 相关的 meta，**有类型提示**，写起来最舒服。

**`useHead`** 更通用，能注入任何 head 内容，包括 script、link、style。

**【录屏提示】** 打开一个页面，写 `useSeoMeta`。

```ts
useSeoMeta({
  title: '产品中心 - 某某科技',
  description: '我们提供全系列的企业数字化解决方案，涵盖软件、硬件和服务。',
  ogTitle: '产品中心 - 某某科技',
  ogDescription: '我们提供全系列的企业数字化解决方案。',
  ogImage: 'https://example.com/og-products.jpg',
  ogType: 'website',
  twitterCard: 'summary_large_image',
})
```

**【录屏提示】** 边写边讲。

几个关键点。

**第一，`title` 和 `description` 是核心。** 标题控制在 60 字符内，描述控制在 160 字符内。**太长会被搜索引擎截断。**

**第二，`og*` 是 Open Graph。** 社交平台（微信、微博、Facebook）分享时用的。**没配的话，分享出来是光秃秃的链接。**

**第三，`twitterCard`。** Twitter 的卡片类型，和 OG 类似。

**第四，所有 `og*` 最好都配上。** 因为微信、钉钉、飞书都读 OG 标签。

**【录屏提示】** 镜头拉近。

**`useSeoMeta` 和 `useHead` 都支持响应式。** 你传 `ref` 或 `computed`，值变化时元信息自动更新。**这在详情页非常重要。**

## 四、动态页面的 SEO（约 2 分 30 秒）

**【录屏提示】** 打开产品详情页，写动态 SEO。

```ts
const { data: product } = await useFetch<Product>(`/api/products/${slug.value}`)

useSeoMeta({
  title: () => `${product.value?.name} - 某某科技`,
  description: () => product.value?.summary,
  ogImage: () => product.value?.cover,
  ogType: 'product',
})
```

**【录屏提示】** 镜头拉近，语气加重。

**注意，我用了函数形式，而不是直接传值。**

为什么？因为 `useSeoMeta` 是**在 SSR 时执行的**，此时 `product` 可能还没取到。**用函数（或 `computed`）能让 Nuxt 在数据到位后再求值。**

**这是动态页面 SEO 的关键技巧。** 如果你直接写 `title: product.value?.name`，可能会拿到 `undefined`。

## 五、canonical 与多语言（约 1 分 30 秒）

**【录屏提示】** 屏幕显示 canonical 用法。

**canonical 解决"重复内容"问题。**

如果你的站有 `example.com` 和 `www.example.com`，或者有分页、筛选参数，搜索引擎可能认为是多个页面。**canonical 告诉它"哪个是权威版本"。**

```ts
useHead({
  link: [
    { rel: 'canonical', href: `https://example.com${route.path}` },
  ],
})
```

**【录屏提示】** 镜头切回讲师。

**多语言站**（比如中英文），还要配 `hreflang`：

```ts
useHead({
  link: [
    { rel: 'alternate', hreflang: 'zh-CN', href: 'https://example.com/zh' },
    { rel: 'alternate', hreflang: 'en', href: 'https://example.com/en' },
  ],
})
```

**企业站如果有国际业务，这个必须配。**

## 六、封装 `usePageSeo`（约 1 分钟）

**【录屏提示】** 新建 `composables/usePageSeo.ts`。

```ts
interface SeoOptions {
  title: string
  description?: string
  image?: string
  type?: 'website' | 'article' | 'product'
}

export function usePageSeo(options: SeoOptions) {
  const config = useRuntimeConfig()
  const siteUrl = config.public.siteUrl

  useSeoMeta({
    title: options.title,
    description: options.description,
    ogTitle: options.title,
    ogDescription: options.description,
    ogImage: options.image,
    ogType: options.type || 'website',
    ogUrl: siteUrl,
    twitterCard: 'summary_large_image',
  })
}
```

**【录屏提示】** 镜头切回讲师。

**封装的好处是：统一默认值。** 每个页面都写一遍 `ogType`、`twitterCard` 太啰嗦。用一个 composable 收口，页面只传关键信息。

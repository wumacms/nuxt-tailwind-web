# 6.6-图片与媒体优化

**【录屏提示】** 开场：讲师出镜，背景为 Lighthouse 报告。

---

## 一、开场白（约 30 秒）

好，欢迎回来。这是第六章的最后一节。

这一节我们讲**图片与媒体优化**。

为什么单独讲？因为在企业站里，**图片往往是性能的最大瓶颈**。一张没优化的 2MB 大图，能让首屏慢好几秒。**图片优化做好了，Lighthouse 分数能提升一大截。**

---

## 二、为什么要用 NuxtImg（约 1 分 30 秒）

**【录屏提示】** 屏幕对比原生 img 和 NuxtImg。

原生 `<img>` 的问题：

**第一，不会自动优化。** 你给它什么格式，它就加载什么。

**第二，不会自动响应式。** 手机也加载桌面大图。

**第三，不会自动懒加载。** 要手动加 `loading="lazy"`。

**第四，不设尺寸会导致 CLS。** 图片加载前占位为 0，加载后撑开，页面"跳一下"。

**【录屏提示】** 镜头切回讲师。

**NuxtImg 就是解决这些问题的。** 它是 Nuxt Image 模块提供的组件。

---

## 三、安装与配置（约 1 分 30 秒）

**【录屏提示】** 终端安装。

```bash
npm install @nuxt/image
```

然后在 `nuxt.config.ts` 里：

```ts
export default defineNuxtConfig({
  modules: ['@nuxt/image'],
  image: {
    domains: ['images.example.com'],
    formats: ['webp', 'avif'],
  },
})
```

**【录屏提示】** 边写边讲。

**第一，`domains` 是允许优化的外部域名。** 用第三方图床时要配。

**第二，`formats` 指定输出格式。** `webp` 和 `avif` 比 `jpg`、`png` 小很多。

---

## 四、NuxtImg 实战（约 3 分钟）

**【录屏提示】** 打开页面，写 NuxtImg。

```vue
<NuxtImg
  src="/images/product.jpg"
  alt="产品图片"
  width="800"
  height="600"
  format="webp"
  quality="80"
  loading="lazy"
  class="w-full h-auto rounded-lg"
/>
```

**【录屏提示】** 边写边讲。

几个关键点。

**第一，`width` 和 `height` 必填。** **这是防 CLS 的关键。** 有了尺寸，浏览器能提前预留空间。

**第二，`format="webp"`。** 输出 WebP 格式，体积更小。

**第三，`quality="80"`。** 质量 80% 是视觉和体积的平衡点。

**第四，`loading="lazy"`。** 懒加载。**但首屏图不要用！**

**【录屏提示】** 镜头拉近，语气加重。

**首屏图（比如 Hero 图）不要懒加载。** 用了 `lazy` 反而会延迟 LCP。

**首屏图应该用 `preload` + 高优先级：**

```vue
<NuxtImg
  src="/hero.jpg"
  preload
  fetchpriority="high"
  width="1200"
  height="800"
/>
```

**这个细节，是 LCP 优化的关键。**

## 五、响应式图片（约 1 分 30 秒）

**【录屏提示】** 写 `sizes` 属性。

```vue
<NuxtImg
  src="/images/hero.jpg"
  sizes="xs:100vw sm:100vw md:50vw lg:800px"
  width="1200"
  height="800"
/>
```

**【录屏提示】** 镜头切回讲师。

**`sizes` 告诉浏览器"不同屏幕下图片显示多宽"。** 浏览器据此选择合适尺寸的图。

**手机加载 400px 宽的图，桌面加载 1200px 的图。** 而不是所有设备都加载 1200px。

**这能大幅减少移动端的流量和加载时间。**

---

## 六、NuxtPicture：多格式回退（约 1 分 30 秒）

**【录屏提示】** 写 NuxtPicture。

```vue
<NuxtPicture
  src="/images/hero.jpg"
  format="avif,webp"
  width="1200"
  height="800"
  alt="Hero 图"
/>
```

**【录屏提示】** 镜头切回讲师。

**`NuxtPicture` 会输出 `<picture>` 标签，支持多格式回退。**

比如：优先 `avif`，不支持则 `webp`，再不支持则原格式。

**兼容性和性能兼顾。** 但输出结构复杂一点，**简单场景用 NuxtImg 就够了。**

---

## 七、图片优化的清单（约 1 分钟）

**【录屏提示】** 屏幕显示优化清单。

我总结一份图片优化清单：

**第一，所有图片都用 `NuxtImg`。**

**第二，`width` 和 `height` 必填，防 CLS。**

**第三，用 `format="webp"`，减小体积。**

**第四，非首屏图加 `loading="lazy"`。**

**第五，首屏图加 `preload` + `fetchpriority="high"`。**

**第六，用 `sizes` 做响应式。**

**第七，控制 `quality`，80% 通常够用。**

**第八，图片本身也要优化。** 上传前压缩，用合适的分辨率。

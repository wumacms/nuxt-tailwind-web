## 一、开场白（约 30 秒）

好，欢迎回来。

这一节我们讲**站点地图**和 **robots**。

它们的作用是**告诉搜索引擎"你的站有哪些页面、哪些能抓、哪些不能抓"**。这是企业站被正确收录的基础设施。

虽然听起来很技术，但配置起来其实很简单。这一节我们把它讲清楚。

---

## 二、sitemap 是什么（约 1 分 30 秒）

**【录屏提示】** 屏幕显示 sitemap.xml 示例。

站点地图（sitemap）是一个 XML 文件，列出网站的所有页面 URL，以及一些元信息（最后更新时间、更新频率、优先级）。

**【录屏提示】** 镜头切回讲师。

**它的价值是：帮助搜索引擎发现和收录你的页面。**

尤其是**动态页面**——比如产品详情、新闻详情。搜索引擎不一定能通过链接爬到所有页面，但 sitemap 可以明确告诉它"这些页面都存在"。

**企业站必做 sitemap。** 这是 SEO 的基础设施。

---

## 三、配置 sitemap（约 3 分钟）

**【录屏提示】** 终端安装。

```bash
npm install @nuxtjs/sitemap
```

然后在 `nuxt.config.ts` 里：

```ts
export default defineNuxtConfig({
  modules: ['@nuxtjs/sitemap'],
  site: {
    url: 'https://example.com',
  },
  sitemap: {
    sources: [
      '/api/__sitemap__/urls',
    ],
  },
})
```

**【录屏提示】** 边写边讲。

几个关键点。

**第一，`site.url` 必填。** sitemap 里的 URL 需要基于一个站点根。

**第二，静态页面自动收录。** 模块会自动扫描 `pages/` 目录，把静态路由加进去。

**第三，动态页面要自己提供。** 用 `sources` 指定一个接口，返回所有动态页面的 URL。

**【录屏提示】** 新建 `server/api/__sitemap__/urls.ts`。

```ts
export default defineEventHandler(async () => {
  const products = await getProducts()
  const news = await getNews()

  return [
    ...products.map(p => ({
      loc: `/products/${p.slug}`,
      lastmod: p.updatedAt,
      changefreq: 'weekly',
      priority: 0.8,
    })),
    ...news.map(n => ({
      loc: `/news/${n.slug}`,
      lastmod: n.date,
      changefreq: 'monthly',
      priority: 0.6,
    })),
  ]
})
```

**【录屏提示】** 镜头拉近，语气放慢。

**`loc` 是路径，`lastmod` 是更新时间，`changefreq` 是更新频率，`priority` 是优先级。**

**`priority` 从 0 到 1。** 首页给 1.0，产品页 0.8，新闻 0.6。**这只是建议，搜索引擎不一定完全遵守，但表达你的意图。**

## 四、robots.txt（约 2 分钟）

**【录屏提示】** 新建 `public/robots.txt`。

```text
User-agent: *
Allow: /
Disallow: /admin/
Disallow: /api/

Sitemap: https://example.com/sitemap.xml
```

**【录屏提示】** 边写边讲。

几个关键点。

**第一，`User-agent: *`。** 对所有爬虫生效。

**第二，`Allow: /`。** 默认允许抓取全部。

**第三，`Disallow`。** 禁止抓取特定路径。**后台、API 接口一定要禁。**

**第四，`Sitemap`。** 告诉爬虫 sitemap 的位置。

**【录屏提示】** 镜头切回讲师。

**注意：`Disallow` 只是"请求"，不是"强制"。** 恶意爬虫可以无视它。**所以敏感页面要靠"登录鉴权"保护，不能只靠 robots。**

**但 robots 对正规搜索引擎有效**，能避免它们浪费抓取配额在你不想暴露的页面上。

---

## 五、使用 Nuxt 的 robots 模块（约 1 分 30 秒）

**【录屏提示】** 镜头切回讲师。

你也可以用 `@nuxtjs/robots` 模块，在 `nuxt.config.ts` 里配置：

```ts
export default defineNuxtConfig({
  modules: ['@nuxtjs/robots'],
  robots: {
    disallow: ['/admin', '/api'],
    allow: '/',
    sitemap: 'https://example.com/sitemap.xml',
  },
})
```

**【录屏提示】** 屏幕显示两种方式对比。

**两种方式都行。** 我个人的习惯是：

- **`public/robots.txt`**：内容固定，简单直接。
- **`@nuxtjs/robots`**：需要按环境（开发/生产）动态生成。

**开发环境不想被收录**，就用模块方式，根据 `NODE_ENV` 切换。

## 六、验证收录（约 1 分 30 秒）

**【录屏提示】** 镜头切回讲师。

配置完之后，要**验证**。

**第一，手动访问。** 打开 `https://example.com/sitemap.xml` 和 `/robots.txt`，看内容对不对。

**第二，用 Google Search Console。** 提交 sitemap，看是否被正确解析。

**第三，用百度站长平台。** 国内企业站必做，提交 sitemap，主动推送 URL。

**第四，site 查询。** 在搜索引擎里搜 `site:example.com`，看收录了多少页面。

**【录屏提示】** 镜头拉近。

**企业站上线后，第一件事就是提交 sitemap。** 不要等搜索引擎自己发现，主动推送能快很多。

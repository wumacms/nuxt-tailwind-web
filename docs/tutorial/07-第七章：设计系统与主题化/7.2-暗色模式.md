# 7.2-暗色模式

**【录屏提示】** 开场：讲师出镜，背景为同一页面的明暗两种效果。

---

## 一、开场白（约 30 秒）

好，欢迎回来。

这一节我们讲**暗色模式**。

现在越来越多的用户习惯在夜间使用暗色模式，甚至有些系统默认就是暗色。**企业站支持暗色模式，是一个体验加分项。**

但暗色模式有个经典的坑——**SSR 下的闪烁（FOUC）**。这一节，我们把它讲透。

---

## 二、暗色模式的实现方式（约 2 分钟）

**【录屏提示】** 屏幕显示三种实现方式对比。

暗色模式有三种实现方式。

**方式一，`prefers-color-scheme`。** 跟随系统设置，用户无法手动切换。

**方式二，class 切换。** 在 `<html>` 上加 `dark` 类，用户可手动切换。

**方式三，data 属性。** 在 `<html>` 上加 `data-theme="dark"`，语义更清晰。

**【录屏提示】** 镜头切回讲师。

**我推荐方式二或三。**

因为企业站通常要给用户一个**切换按钮**。方式一做不到。

**方式和三的区别不大**，class 更简单，data 属性语义更好。我个人习惯用 class，因为 Tailwind 的 `dark:` 变体默认就是基于 class 的。

---

## 三、配置 Tailwind 的 dark 变体（约 1 分 30 秒）

**【录屏提示】** 打开 `main.css`。

V4 里，默认的 `dark:` 是跟随**系统设置**的。要改成"基于 class"，需要加一行：

```css
@import "tailwindcss";
@custom-variant dark (&:where(.dark, .dark *));
```

**【录屏提示】** 边写边讲。

**这行 `@custom-variant` 的意思是：`dark:` 变体在 `.dark` 类或其子元素上生效。**

配置完之后，你就能这样用：

```html
<div class="bg-white dark:bg-gray-900 text-gray-900 dark:text-white">
```

**【录屏提示】** 镜头切回讲师。

**这行配置很多人不知道，是 V4 的一个变化。** V3 时代是在 `tailwind.config.js` 里配 `darkMode: 'class'`。**V4 搬到了 CSS 里。**

---

## 四、用语义令牌简化（约 2 分钟）

**【录屏提示】** 镜头拉近，语气放慢。

**在每个元素上写 `dark:` 很啰嗦。** 更好的做法是——**用语义令牌。**

我们 7.1 定义的语义令牌，就是为这个场景准备的。

```css
@theme {
  --color-background: #ffffff;
  --color-foreground: #111827;
  --color-surface: #f9fafb;
  --color-border: #f3f4f6;
}

/* 暗色覆盖 */
.dark {
  --color-background: #0f172a;
  --color-foreground: #f1f5f9;
  --color-surface: #1e293b;
  --color-border: #334155;
}
```

**【录屏提示】** 边写边讲，切浏览器切换。

**然后组件里只用 `bg-background text-foreground border-border`，不用写 `dark:`。**

**切换 `.dark` 类，所有令牌自动变化，全站变暗。**

**【录屏提示】** 镜头切回讲师。

**这就是语义令牌的威力。** 组件代码里没有任何"暗色逻辑"，只是用了语义化的颜色。

**暗色模式变成"令牌层的事"，不是"组件层的事"。** 这是专业设计系统的做法。

## 五、实现切换按钮（约 2 分钟）

**【录屏提示】** 新建 `composables/useTheme.ts`。

```ts
export function useTheme() {
  const isDark = useState('theme-dark', () => false)

  function apply(dark: boolean) {
    if (import.meta.client) {
      document.documentElement.classList.toggle('dark', dark)
      localStorage.setItem('theme', dark ? 'dark' : 'light')
    }
  }

  function toggle() {
    isDark.value = !isDark.value
    apply(isDark.value)
  }

  function init() {
    if (import.meta.client) {
      const saved = localStorage.getItem('theme')
      const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches
      isDark.value = saved ? saved === 'dark' : prefersDark
      apply(isDark.value)
    }
  }

  return { isDark, toggle, init }
}
```

**【录屏提示】** 边写边讲。

几个关键点。

**第一，`useState` 是 Nuxt 的全局状态。** 比 `ref` 更适合跨组件共享。

**第二，`localStorage` 保存用户选择。** 下次访问记住。

**第三，`prefers-color-scheme` 读取系统设置。** 作为默认值。

**第四，所有 `window`、`document`、`localStorage` 访问都在 `import.meta.client` 判断里。** 避开 SSR 报错。

## 六、解决 SSR 闪烁（约 2 分钟）

**【录屏提示】** 镜头拉近，语气加重。

**这是暗色模式最关键的坑。**

**问题现象**：用户打开页面，先看到白色（默认），然后突然变暗。**这个闪烁很难看。**

**原因**：`useTheme` 的 `init` 是在 Vue 挂载后执行的，此时 HTML 已经渲染成白色了。

**解决方案：在内联脚本里，尽早设置 `dark` 类。**

**【录屏提示】** 打开 `nuxt.config.ts`，加 `app.head`。

```ts
export default defineNuxtConfig({
  app: {
    head: {
      script: [
        {
          innerHTML: `
            (function() {
              const saved = localStorage.getItem('theme');
              const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
              if (saved === 'dark' || (!saved && prefersDark)) {
                document.documentElement.classList.add('dark');
              }
            })();
          `,
          type: 'text/javascript',
        },
      ],
    },
  },
})
```

**【录屏提示】** 边写边讲。

**这个脚本在页面渲染前执行**，会立刻给 `<html>` 加上 `dark` 类。**这样首屏就是暗的，不会闪。**

**【录屏提示】** 镜头切回讲师。

**注意，这个脚本必须是"内联"的。** 不能放在外部文件里，因为外部文件是异步加载的，会晚于渲染。

**这是暗色模式 SSR 的"标准解法"。** 你记住这个模式。

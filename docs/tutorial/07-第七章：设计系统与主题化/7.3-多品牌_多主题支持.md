# 7.3-多品牌_多主题支持

**【录屏提示】** 开场：讲师出镜，背景为同一页面两种品牌色。

---

## 一、开场白（约 30 秒）

好，欢迎回来。

这一节我们讲**多品牌/多主题**。

什么场景需要它？

比如一个集团，旗下有多个子品牌，每个品牌有自己的主色。或者一个 SaaS 产品，允许客户自定义主题色。

这一节，我们讲清楚**怎么用一套代码，支持多套主题**。

---

## 二、两种主题化方式（约 2 分 30 秒）

**【录屏提示】** 屏幕显示两种方式的对比。

**方式一，构建时主题。** 不同品牌编译出不同的产物。

**优点**：运行时零开销，产物小。

**缺点**：改主题要重新构建、重新部署。

**方式二，运行时主题。** 一套产物，运行时切换。

**优点**：灵活，切换即时生效。

**缺点**：所有主题的 CSS 都打包进去，体积略大。

**【录屏提示】** 镜头切回讲师。

**怎么选？**

- **品牌数量少、不常变** → 构建时主题
- **品牌数量多、需要动态切换** → 运行时主题

**企业站通常用运行时主题**，因为一次部署，多个品牌都能用。

---

## 三、运行时主题的实现（约 3 分钟）

**【录屏提示】** 打开 `main.css`，写主题定义。

```css
@import "tailwindcss";

@theme {
  --color-primary: var(--theme-primary);
  --color-primary-hover: var(--theme-primary-hover);
  --color-accent: var(--theme-accent);
  --radius-md: var(--theme-radius-md);
}

/* 品牌 A（默认） */
:root {
  --theme-primary: #2563eb;
  --theme-primary-hover: #1d4ed8;
  --theme-accent: #f97316;
  --theme-radius-md: 12px;
}

/* 品牌 B */
[data-theme="brand-b"] {
  --theme-primary: #059669;
  --theme-primary-hover: #047857;
  --theme-accent: #f59e0b;
  --theme-radius-md: 4px;
}

/* 品牌 C */
[data-theme="brand-c"] {
  --theme-primary: #7c3aed;
  --theme-primary-hover: #6d28d9;
  --theme-accent: #ec4899;
  --theme-radius-md: 9999px;
}
```

**【录屏提示】** 边写边讲，逐段解释。

**关键设计：`@theme` 里的令牌，指向 `--theme-*` 变量。**

**而 `--theme-*` 的值，根据 `[data-theme]` 属性变化。**

**所以在 `<html>` 上切换 `data-theme` 属性，全站主题就变了。**

**【录屏提示】** 镜头切回讲师。

**注意，我连圆角都做了主题化。** 品牌 C 的圆角是 `9999px`，所有按钮都是胶囊形。**这就是"设计语言"的差异，不只是颜色。**

**好的主题化，能改变"整个设计风格"，而不只是换色。**

## 四、运行时切换（约 2 分钟）

**【录屏提示】** 新建 `composables/useBrand.ts`。

```ts
type BrandKey = 'brand-a' | 'brand-b' | 'brand-c'

export function useBrand() {
  const brand = useState<BrandKey>('brand', () => 'brand-a')

  function set(next: BrandKey) {
    brand.value = next
    if (import.meta.client) {
      document.documentElement.setAttribute('data-theme', next)
      localStorage.setItem('brand', next)
    }
  }

  function init() {
    if (import.meta.client) {
      const saved = localStorage.getItem('brand') as BrandKey | null
      if (saved) set(saved)
    }
  }

  return { brand, set, init }
}
```

**【录屏提示】** 边写边讲。

**思路和 `useTheme` 几乎一样。** 读 localStorage，设置 data 属性。

**注意和暗色模式的配合。**

如果同时支持"品牌 + 暗色"，那选择器要这样写：

```css
[data-theme="brand-b"] { ... }
[data-theme="brand-b"].dark { ... }
```

**两个维度要正交组合。** 品牌控制"色相"，暗色控制"明度"。

## 五、用 app.config.ts 管理（约 1 分 30 秒）

**【录屏提示】** 打开 `app.config.ts`。

```ts
export default defineAppConfig({
  brands: {
    'brand-a': { name: '某某科技', logo: '/logo-a.svg' },
    'brand-b': { name: '某某环保', logo: '/logo-b.svg' },
    'brand-c': { name: '某某教育', logo: '/logo-c.svg' },
  },
})
```

**【录屏提示】** 镜头切回讲师。

**用 `app.config` 管理品牌元数据——名称、logo 等。**

**颜色和圆角放 CSS，其他元数据放 `app.config`。** 各司其职。

**这样加一个新品牌，只需要在 CSS 里加一组变量，在 `app.config` 里加一条记录。**

## 六、无闪烁初始化（约 1 分钟）

**【录屏提示】** 镜头拉近，语气放慢。

**多品牌也有闪烁问题。** 和暗色模式一样，要在内联脚本里尽早设置。

```html
<script>
  (function() {
    const brand = localStorage.getItem('brand');
    if (brand) document.documentElement.setAttribute('data-theme', brand);
    // 暗色逻辑...
  })();
</script>
```

**把这个脚本和暗色模式的脚本合并**，一次性处理所有"首屏主题"。

**这样首屏就不会"先蓝后绿"了。**

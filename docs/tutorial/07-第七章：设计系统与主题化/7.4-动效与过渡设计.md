# 7.4-动效与过渡设计

**【录屏提示】** 开场：讲师出镜，背景为各种动效示例。

---

## 一、开场白（约 30 秒）

好，欢迎回来。

这一节我们讲**动效与过渡**。

动效是一把双刃剑。**用得好，体验流畅、有质感；用不好，用户觉得花哨、卡顿。**

这一节，我们讲清楚**"克制"的动效设计**——什么时候该动，什么时候不该动，动多久合适。

---

## 二、动效的三个原则（约 2 分钟）

**【录屏提示】** 屏幕显示三个原则。

**第一，动效要有"理由"。**

不要为了动而动。动效的目的通常是：

- **引导注意力**（新内容出现）
- **表达状态变化**（按钮点击、加载中）
- **建立空间感**（弹窗从哪来、回哪去）
- **提供反馈**（提交成功、校验失败）

**如果以上都不满足，就别加动效。**

**第二，动效要"快"。**

用户体验研究显示，**100-300ms** 是最舒服的过渡时间。

- 太短（< 100ms）：用户感觉不到
- 太长（> 400ms）：用户觉得慢

**第三，动效要"克制"。**

**一屏之内，同时运动的元素不要超过 3 个。** 太多会分散注意力。

**【录屏提示】** 镜头切回讲师。

**记住一句话：好的动效，是用户"没注意到"的动效。** 它让体验顺滑，但不抢戏。

## 三、Tailwind 的 transition（约 2 分 30 秒）

**【录屏提示】** 打开代码，写 transition。

```html
<button class="transition-colors duration-200 hover:bg-brand-600">
  按钮
</button>

<div class="transition-all duration-300 hover:shadow-lg hover:-translate-y-1">
  卡片
</div>
```

**【录屏提示】** 边写边讲。

几个关键点。

**第一，`transition-colors` 只过渡颜色属性。** 比 `transition-all` 性能好。

**第二，`duration-200` 是 200ms。** Tailwind 默认提供 `75`、`100`、`150`、`200`、`300`、`500`、`700`、`1000`。

**第三，`transition-all` 慎用。** 它会过渡所有属性，包括 `width`、`height`，可能导致重排。**优先用具体的属性。**

**【录屏提示】** 屏幕显示常用 transition 类。

- `transition-colors` — 颜色
- `transition-opacity` — 透明度
- `transition-transform` — 变换
- `transition-shadow` — 阴影
- `transition-all` — 全部（慎用）

## 四、`prefers-reduced-motion`（约 2 分钟）

**【录屏提示】** 镜头拉近，语气加重。

**这是最重要的一节内容。**

有些用户对动画敏感，可能会**眩晕、头痛**。操作系统提供了"减少动效"的设置。

**Tailwind 提供了 `motion-safe` 和 `motion-reduce` 变体。**

```html
<div class="motion-safe:transition-transform motion-safe:hover:scale-105">
  卡片
</div>

<div class="motion-reduce:transition-none">
  内容
</div>
```

**【录屏提示】** 镜头切回讲师。

**`motion-safe:` 表示"用户没有开启减少动效时生效"。**

**`motion-reduce:` 表示"用户开启了减少动效时生效"。**

**我的建议是：所有装饰性动效，都用 `motion-safe:` 包裹。**

```html
<div class="motion-safe:transition-all motion-safe:hover:-translate-y-1">
```

**这样默认开启减少动效的用户，就看到静态版本。**

**这是 a11y 的基本要求，也是企业项目的专业体现。**

## 五、关键帧动画（约 2 分钟）

**【录屏提示】** 打开 `theme.css`，定义动画。

```css
@theme {
  --animate-fade-in: fade-in 0.3s ease-out;
  --animate-slide-up: slide-up 0.4s ease-out;

  @keyframes fade-in {
    from { opacity: 0; }
    to { opacity: 1; }
  }

  @keyframes slide-up {
    from { opacity: 0; transform: translateY(1rem); }
    to { opacity: 1; transform: translateY(0); }
  }
}
```

**【录屏提示】** 边写边讲。

**V4 里，`--animate-*` 定义动画，`@keyframes` 写在 `@theme` 里。**

**然后用 `animate-fade-in`、`animate-slide-up`。**

**【录屏提示】** 镜头切回讲师。

**常用的几个动画：**

- **fade-in**：淡入，用于 Toast、Modal
- **slide-up**：从下滑入，用于抽屉、卡片
- **scale-in**：从中心缩放，用于 Popover
- **spin**：旋转，用于 Loading

**不要做太花哨的动画**——弹跳、抖动、翻转，这些在企业站里都不合适。

## 六、滚动动效（约 1 分 30 秒）

**【录屏提示】** 镜头切回讲师。

**滚动时元素淡入**，是现代网站常见的动效。

**实现方式：用 `IntersectionObserver` 检测元素是否进入视口。**

```ts
// composables/useReveal.ts
export function useReveal() {
  const el = ref<HTMLElement>()

  onMounted(() => {
    if (!el.value) return
    const observer = new IntersectionObserver(
      ([entry]) => {
        if (entry.isIntersecting) {
          entry.target.classList.add('is-visible')
          observer.unobserve(entry.target)
        }
      },
      { threshold: 0.1 }
    )
    observer.observe(el.value)
  })

  return { el }
}
```

**配合 CSS：**

```css
.reveal {
  opacity: 0;
  transform: translateY(2rem);
  transition: opacity 0.6s ease, transform 0.6s ease;
}
.reveal.is-visible {
  opacity: 1;
  transform: translateY(0);
}
```

**【录屏提示】** 镜头拉近，语气放慢。

**滚动动效要"克制"。**

**不要每个元素都动**，那会让页面一直"抖"。**只在关键区块用**，比如首页的价值主张区。

**而且一定要用 `motion-safe:`**，尊重用户的系统设置。
